## g10-aex-l06-w01: Simplify (x² + 2x + 4)/(x³ − 8) and state the excluded real value of x.

1. Factor the denominator: (x³ − 8) = (x − 2)(x² + 2x + 4).

2. Keep the restriction from the original denominator: x ≠ 2.

3. Cancel the common factor (x² + 2x + 4) only where it is nonzero.

4. Remaining expression: 1/(x − 2).

5. Answer: 1/(x − 2), x ≠ 2. Check by multiplying the simplified form by the original denominator.

**Answer:** 1/(x − 2); x ≠ 2. **Misconception:** Preserve every sign, factor, restriction and original expression; check the final result by reversing the operation.

5. Answer: 5/(x + 2), x ≠ -2. Multiply back to verify the common denominator.

**Answer:** 5/(x + 2); x ≠ -2. **Misconception:** Preserve every sign, factor, restriction and original expression; check the final result by reversing the operation.
