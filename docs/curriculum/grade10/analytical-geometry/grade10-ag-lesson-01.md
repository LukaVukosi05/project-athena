## g10-ag-l01-w01: On a Cartesian plane A(-4; -1) and B(-1; -5). Find the exact distance AB.

Visual contract: {"family": "grade10_analytical", "values": {"lesson": 1, "model": "segment", "points": [[-4, -1], [-1, -5]], "mode": "distance", "dx": 3, "dy": -4, "answer": "AB = 5 units"}}

1. Plot A(-4; -1) and B(-1; -5) on the same axes.

2. Draw horizontal run Δx=3 and vertical rise Δy=-4.

3. Use AB²=(Δx)²+(Δy)²=3²+(-4)²=25.

4. Take the positive root: AB=√25=5 units.

5. Answer: AB = 5 units. Check by squaring: 5²=9+16.

**Answer:** AB = 5 units. **Misconception:** Keep the coordinates and axis scales visible; derive each conclusion from exact differences.
