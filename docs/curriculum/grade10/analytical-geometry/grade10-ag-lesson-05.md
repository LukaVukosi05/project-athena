## g10-ag-l05-w01: Classify ABCD using its coordinates: A(-4; -1), B(0; -1), C(1; 1), D(-3; 1).

Visual contract: {"family": "grade10_analytical", "values": {"lesson": 5, "model": "quadrilateral", "points": [[-4, -1], [0, -1], [1, 1], [-3, 1]], "mode": "parallelogram", "answer": "ABCD is a parallelogram"}}

1. Plot A, B, C and D at their stated coordinates.

2. Draw AB, BC, CD and DA in that order.

3. Compute the horizontal and vertical changes for opposite sides.

4. Both pairs of opposite sides have equal direction vectors; adjacent vectors are neither perpendicular nor equal in length.

5. Answer: ABCD is a parallelogram. A sketch alone is not a proof.

**Answer:** ABCD is a parallelogram. **Misconception:** Keep the coordinates and axis scales visible; derive each conclusion from exact differences.

## g10-ag-l05-w05: Classify ABCD using its coordinates: A(-5; -3), B(2; -3), C(0; 0), D(-4; 0).

Visual contract: {"family": "grade10_analytical", "values": {"lesson": 5, "model": "quadrilateral", "points": [[-5, -3], [2, -3], [0, 0], [-4, 0]], "mode": "trapezium", "answer": "ABCD is a trapezium"}}
