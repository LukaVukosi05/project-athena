## g10-eei-l01-w02: Simplify 4x⁰ + x^−2 for x ≠ 0.

Visual contract: {"family": "grade10_equations", "values": {"lesson": 1, "kind": "exponent", "a": 4, "b": 2, "c": 2, "d": 3, "form": "zero", "result": "4 + 1/x²"}}

1. The zero exponent applies to x alone and x ≠ 0.

2. Write x⁰ = 1, so 4x⁰ = 4.

3. Rewrite x^−2 = 1/x².

4. Add the two terms without combining unlike powers.

5. Answer: 4 + 1/x²; x ≠ 0. At x = 1 both forms equal 5.

**Answer:** 4 + 1/x². **Misconception:** Check the first sign, branch, equation, unit or domain restriction against the original question.

## g10-eei-l01-w03: Simplify (x^5 · x^1)/x^7 for x ≠ 0.

Visual contract: {"family": "grade10_equations", "values": {"lesson": 1, "kind": "exponent", "a": 5, "b": 2, "c": 3, "d": 4, "m": 5, "k": 1, "form": "quotient", "result": "1/x"}}

1. Identify the same base x in both numerator factors.

2. Add numerator exponents: x^5 · x^1 = x^6.

3. Divide like bases: x^6/x^7 = x^−1.

4. Rewrite the negative power using x^−1 = 1/x (x ≠ 0).

5. Answer: 1/x, x ≠ 0. Multiplying by x gives 1.
