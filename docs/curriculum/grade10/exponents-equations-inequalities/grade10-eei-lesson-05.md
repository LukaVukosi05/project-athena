## g10-eei-l05-w01: Solve simultaneously: x + y = 4 and x − y = 2.

1. Write both equations in aligned columns: x+y=4 and x−y=2.

2. Add the equations: 2x = 6.

3. Divide by 2: x = 3.

4. Substitute into x+y=4: y=4−3=1.

5. Answer: x = 3, y = 1. Check x−y=3−1=2.

**Answer:** x = 3, y = 1. **Misconception:** Check the first sign, branch, equation, unit or domain restriction against the original question.
