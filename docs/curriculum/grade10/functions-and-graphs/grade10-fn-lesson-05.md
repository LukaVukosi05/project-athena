## g10-fn-l05-w01: For y = -2·sin θ − 3, give the midline and the value when θ=0°. Explain how a affects the graph.

1. Start with the parent sine curve on 0°≤θ≤360°.

2. Multiply each defined parent y-value by a=-2; negative a reflects across the x-axis.

3. Shift the multiplied graph by q=-3, so the centre line is y=-3.

4. At θ=0°, sine is 0; hence y(0°)=-3.

5. Answer: midline y = -3; y(0°) = -3. Tangent has no amplitude; |a| scales it vertically.

**Answer:** midline y = -3; y(0°) = -3. **Misconception:** Keep domain restrictions, original points and the meaning of a and q visible through every graph step.
