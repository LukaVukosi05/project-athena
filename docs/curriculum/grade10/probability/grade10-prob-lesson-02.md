## g10-prob-l02-w01: In a class of 7, 3 choose activity A, 3 choose B and 0 choose both. How many choose A only?

Visual contract: {"family": "grade10_probability", "values": {"lesson": 2, "model": "venn", "a_only": 3, "b_only": 3, "both": 0, "neither": 1, "total": 7, "a": 3, "b": 3, "union": 6, "answer": "3"}}

1. Draw the universal set with two overlapping circles A and B for 7 learners.

2. Put 0 into the overlap first.

3. Subtract the overlap: A-only=3−0=3, B-only=3−0=3.

4. Outside both=7−(3+0+3)=1; check all four regions total 7.

5. Answer: A only = 3. Every learner is counted exactly once.

**Answer:** 3. **Misconception:** The overlap is counted once in a union; complement requires both disjointness and exhaustive coverage.
