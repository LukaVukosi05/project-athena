## g10-prob-l03-w01: A sample space has 7 outcomes: A-only 3, B-only 3, both 0, neither 1. Find P(A or B).

Visual contract: {"family": "grade10_probability", "values": {"lesson": 3, "model": "venn", "a_only": 3, "b_only": 3, "both": 0, "neither": 1, "total": 7, "a": 3, "b": 3, "union": 6, "answer": "6/7"}}

1. Mark the four disjoint regions A-only=3, overlap=0, B-only=3, outside=1.

2. Calculate |A|=3 and |B|=3; use the common denominator |S|=7.

3. |A∪B|=3+3−0=6; the overlap was counted twice in |A|+|B|.

4. The requested favourable count for A or B is 6; divide by 7.

5. Answer: P(A or B) = 6/7. All four disjoint regions add to 7.

**Answer:** 6/7. **Misconception:** The overlap is counted once in a union; complement requires both disjointness and exhaustive coverage.
