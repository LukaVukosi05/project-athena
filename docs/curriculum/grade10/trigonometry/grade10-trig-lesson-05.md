## g10-trig-l05-w01: A ladder leaning against a wall forms a right triangle: vertical rise 3 m and horizontal run 4 m. Find the angle θ to the ground to one decimal place.

Visual contract: {"family": "grade10_trigonometry", "values": {"lesson": 5, "family": "grade10_trigonometry", "opposite": 3, "adjacent": 4, "hypotenuse": 5, "orientation": "opposite-vertical", "model": "application", "angle": 36.9, "context": "ladder leaning against a wall", "answer": "θ ≈ 36.9°"}}

1. Draw and label the rise 3 m, run 4 m and ground angle θ.

2. Check the hypotenuse: √(3²+4²)=5 m.

3. The rise is opposite θ and the run adjacent: tan θ=3/4.

4. Apply inverse tangent: θ=arctan(3/4)≈36.8699°.

5. Answer: θ ≈ 36.9°. The angle is acute and the given rise/run ratio matches tan θ.

**Answer:** θ ≈ 36.9°. **Misconception:** Identify the marked reference angle, keep coordinate signs and test the original condition.
