## g11-ag-l01-w01: Find the distance between A(-3, -1) and B(1, 2).

Visual values: `{"family": "grade11_analytical", "values": {"mode": "distance", "a": [-3, -1], "b": [1, 2], "dx": 4, "dy": 3, "length": 5}}`

1. Plot A(-3, -1) and B(1, 2) on the same coordinate plane.

2. Draw the horizontal and vertical legs: Δx = 1 − (-3) = 4; Δy = 2 − (-1) = 3.

3. Use Pythagoras: AB² = (Δx)² + (Δy)² = 16 + 9 = 25.

4. Distance cannot be negative, so AB = √25 = 5.

5. Answer: AB = 5 units. Check: 4² + 3² = 5².

Answer: 5 units. Check: Answer: AB = 5 units. Check: 4² + 3² = 5².
