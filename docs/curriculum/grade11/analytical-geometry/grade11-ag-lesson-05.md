## g11-ag-l05-w01: Line AB through A(-3, -1) and B(0, 3) has a parallel line through P(-2, -3). Find the equation of the new line in y = mx + c form.

1. Plot A(-3, -1), B(0, 3) and the new line point P(-2, -3).

2. From A to B, rise = 4 and run = 3, so mAB = 4/3.

3. Parallel lines have equal gradients: mnew = 4/3.

4. Substitute P into y = mnew x + c: c = -3 − (4/3)(-2) = -1/3.

5. Answer: y = 4/3x − 1/3. Check: P lies on the new line and its gradient is 4/3.

Answer: y = 4/3x − 1/3. Check: Answer: y = 4/3x − 1/3. Check: P lies on the new line and its gradient is 4/3.
