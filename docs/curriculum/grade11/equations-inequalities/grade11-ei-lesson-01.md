## g11-ei-l01-w01 — Complete the square for f(x) = x² + 6x + 6 and state its turning point.

Visual values: `{"family": "grade11_equations", "values": {"mode": "square", "b": 6, "c": 6}}`

1. Half the coefficient of x: 6 ÷ 2 = 3. The square will use (x + 3).

2. Square the half-coefficient: (3)² = 9. Add and subtract this amount.

3. f(x) = (x + 3)² − 3.

4. The square is smallest when x = -3, so the turning point is (-3; -3).

5. Answer: (-3; -3). Expand (x + 3)² − 3 to recover x² + 6x + 6.

Answer: (-3; -3). Check: Answer: (-3; -3). Expand (x + 3)² − 3 to recover x² + 6x + 6.
