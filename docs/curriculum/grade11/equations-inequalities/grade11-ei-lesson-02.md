## g11-ei-l02-w01 — Solve x² + 4x + 3 = 0 by factorisation.

Visual values: `{"family": "grade11_equations", "values": {"mode": "roots", "b": 4, "c": 3}}`

1. Find two numbers whose sum is 4 and product is 3. Here they are 3 and 1.

2. Split the middle term: x² + 3x + 1x + 3 = 0.

3. Factor: (x + 3)(x + 1) = 0.

4. Use the zero-product rule: x − (-3) = 0 or x − (-1) = 0.

5. Answer: x = -3 or x = -1. Substituting each value into x² + 4x + 3 gives zero.

Answer: x = -3 or x = -1. Check: Answer: x = -3 or x = -1. Substituting each value into x² + 4x + 3 gives zero.
