## g11-ei-l03-w01 — Solve x² + 6x + 7 = 0 using the quadratic formula. Give exact roots.

Visual values: `{"family": "grade11_equations", "values": {"mode": "formula", "b": 6, "c": 7, "discriminant": 8}}`

1. Identify a = 1, b = 6 and c = 7 in ax² + bx + c = 0.

2. Calculate b² − 4ac = (6)² − 4(1)(7) = 8.

3. Substitute: x = (−(6) ± √8) ÷ 2.

4. Since √8 = 2√2, divide both terms by 2 to get x = -3 ± √2.

5. Answer: x = -3 ± √2. Each candidate satisfies (x + 3)² = 2, hence the original equation.

Answer: x = -3 ± √2. Check: Answer: x = -3 ± √2. Each candidate satisfies (x + 3)² = 2, hence the original equation.

Answer: x = -2 ± √14. Each candidate satisfies (x + 2)² = 14, hence the original equation.
