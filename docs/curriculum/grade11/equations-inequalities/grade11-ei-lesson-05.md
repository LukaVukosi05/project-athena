## g11-ei-l05-w01 — Find both intersections of y = x² + 3x + 5 and y = -1x + 2.

Visual values: `{"family": "grade11_equations", "values": {"mode": "intersection", "b": 3, "c": 5, "m": -1, "d": 2}}`

1. At an intersection the y-values are equal: x² + 3x + 5 = -1x + 2.

2. Subtract the line from both sides to preserve equality: x² + 4x + 3 = 0.

3. Factor (x + 3)(x + 1) = 0, so x = -3 or x = -1.

4. Use the straight line y = -1x + 2: y(-3) = 5 and y(-1) = 3.

5. Answer: (-3; 5) and (-1; 3). Substitute both ordered pairs into BOTH original equations.

Answer: (-3; 5) and (-1; 3). Check: Answer: (-3; 5) and (-1; 3). Substitute both ordered pairs into BOTH original equations.
