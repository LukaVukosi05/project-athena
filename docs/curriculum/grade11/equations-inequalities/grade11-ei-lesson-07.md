Between the roots the product is negative; outside them it is positive. Select the between region for < 0. Exclude both zero endpoints. Answer: -4 < x < 3. - g11-ei-l07-r02: Choose a method and justify it. Find both intersections of y = x² − 2x − 9 and y = -1x + 3. Options: (-3; -1) and (4; 6) | x = -3 or x = 4 | (3; 6) and (-4; -1) | (-3; 6) and (4; -1). Correct: (-3; 6) and (4; -1). Select the appropriate quadratic method. At an intersection the y-values are equal: x² − 2x − 9 = -1x + 3. Subtract the line from both sides to preserve equality: x² − 1x − 12 = 0. Factor (x + 3)(x − 4) = 0, so x = -3 or x = 4. Use the straight line y = -1x + 3: y(-3) = 6 and y(4) = -1. Answer: (-3; 6) and (4; -1). Substitute both ordered pairs into BOTH original equations.

- g11-ei-l07-r03: Choose a method and justify it. Solve x² + 2x = 0 by factorisation. Options: x = -2 | x = 0 | x = -2 or x = 0 | x = 2 or x = 0. Correct: x = -2 or x = 0. Select the appropriate quadratic method. Find two numbers whose sum is 2 and product is 0. Here they are 2 and 0. Split the middle term: x² + 2x + 0x + 0 = 0. Factor: (x + 2)(x − 0) = 0. Use the zero-product rule: x − (-2) = 0 or x − (0) = 0. Answer: x = -2 or x = 0. Substituting each value into x² + 2x gives zero.
