## g11-euc-l05-w01: From external point P, tangents PA and PB touch a circle with centre O. If OP = 5 cm and OA = 3 cm, calculate both tangent lengths.

Visual values: `{"family": "grade11_euclidean", "values": {"mode": "tangents", "radius": 3, "tangent": 4, "external": 5}}`

1. Join O to point of contact A. Radius OA = 3 cm is perpendicular to tangent PA.

2. Right triangle OAP has hypotenuse OP = 5 cm and leg OA = 3 cm.

3. Apply Pythagoras: PA² = OP² − OA² = 25 − 9 = 16 cm².

4. The positive tangent length PA = 4 cm. Tangents from the same external point are equal.

5. Answer: PA = PB = 4 cm. Check: 3² + 4² = 5².

Answer: PA = PB = 4 cm. Check: Answer: PA = PB = 4 cm. Check: 3² + 4² = 5².

Right triangle OAP has hypotenuse OP = 104 cm and leg OA = 40 cm. Apply Pythagoras: PA² = OP² − OA² = 10816 − 1600 = 9216 cm². The positive tangent length PA = 96 cm. Tangents from the same external point are equal. Answer: PA = PB = 96 cm. Check: 40² + 96² = 104².
