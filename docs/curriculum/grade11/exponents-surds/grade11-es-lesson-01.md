## g11-es-l01-w01: Evaluate 27^(1/3) using a positive 3th root.

Visual contract: `{"family": "grade11_exponents_surds", "values": {"family": "root_power", "base": 27, "index": 3, "power": 1, "root": 3, "lesson": 1}}`

1. Identify the base 27 and rational exponent 1/3.

2. The denominator 3 means take the positive 3th root of 27.

3. Because 3^3 = 27, that root is 3.

4. Raise 3 to the numerator 1: 3^1 = 3.

5. Answer: 3. Check: 3^3 = 27^1.

**Answer:** 3. **Check:** Answer: 3. Check: 3^3 = 27^1.
