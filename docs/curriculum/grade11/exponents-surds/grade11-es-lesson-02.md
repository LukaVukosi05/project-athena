## g11-es-l02-w01: Simplify x^(3/3) × x^(1/3) ÷ x^(1/3), for x > 0.

Visual contract: `{"family": "grade11_exponents_surds", "values": {"family": "exponent_laws", "a": 3, "b": 1, "c": 1, "denominator": 3, "lesson": 2}}`

1. Keep the common positive base x and denominators 3.

2. Multiplication adds numerator exponents: 3 + 1 = 4.

3. Division subtracts numerator exponent 1: 4 − 1 = 3.

4. Reduce 3/3 where possible: write x^1; retain x > 0.

5. Answer: x^1, x > 0. Substitute x = 27 into both forms to check.

**Answer:** x^1. **Check:** Answer: x^1, x > 0. Substitute x = 27 into both forms to check.
