## g11-es-l05-w01: Rationalise the denominator of 3/√3 and simplify.

Visual contract: `{"family": "grade11_exponents_surds", "values": {"family": "rationalise", "numerator": 3, "radicand": 3, "lesson": 5}}`

1. Start with 3/√3; √3 is nonzero.

2. Multiply numerator and denominator by √3/√3, which equals one.

3. The numerator becomes 3√3.

4. The denominator becomes (√3)² = 3.

5. Answer: 1√3. Divide numerator and denominator by 3; both forms have the same value.

**Answer:** 1√3. **Check:** Answer: 1√3. Divide numerator and denominator by 3; both forms have the same value.
