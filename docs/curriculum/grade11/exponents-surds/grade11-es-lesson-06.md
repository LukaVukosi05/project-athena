## g11-es-l06-w01: Solve √(x + 10) = x − 2 in real numbers.

Visual contract: `{"family": "grade11_exponents_surds", "values": {"family": "surd_equation", "offset": 10, "rhs_offset": 2, "valid": 6, "rejected": -1, "lesson": 6}}`

1. The principal root is nonnegative, so x − 2 ≥ 0 and x ≥ 2.

2. Square both sides: x + 10 = (x − 2)².

3. Solve the resulting quadratic to get candidates 6 and -1.

4. Substitute into the ORIGINAL equation: x = -1 fails because its right side is negative.

5. Answer: x = 6. At x = 6, √(6+10) = 4 and 6 − 2 = 4.

**Answer:** x = 6. **Check:** Answer: x = 6. At x = 6, √(6+10) = 4 and 6 − 2 = 4.
