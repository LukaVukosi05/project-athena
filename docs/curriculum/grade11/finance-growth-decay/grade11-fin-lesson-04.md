## g11-fin-l04-w01: A machine costs R6,350.00 and depreciates by 5% annually for 3 years using straight-line depreciation on original cost. Find its book value to the nearest cent.

Question-specific visual values: `{"family": "grade11_finance", "values": {"mode": "decay", "principal": "6350", "rate": "0.05", "years": 3, "simple": true}}`

1. Original cost P = R6,350.00, depreciation rate i = 0.05, n = 3.

2. Straight-line depreciation uses A = P(1 − in).

3. Substitute A = 6,350.00 × (1 − 0.05 × 3).

4. Calculate A = R5,397.50; this is the book value, not the total loss.

5. Answer: Book value = R5,397.50. Check 0 < A < the original R6,350.00.

Answer: Book value = R5,397.50. Check: Answer: Book value = R5,397.50. Check 0 < A < the original R6,350.00.
