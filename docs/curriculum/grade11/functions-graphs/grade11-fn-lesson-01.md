## g11-fn-l01-w01: For f(x) = 1(x − 1)² + 0, find the turning point and identify its graph.

Visual values: `{"family": "grade11_functions", "values": {"mode": "quadratic", "a": 1, "p": -1, "q": 0, "vertex": [1, 0]}}`

1. Start with the parent parabola y = x² and mark its turning point (0, 0).

2. The bracket x − 1 moves the graph 1 units right.

3. The + 0 term shifts the graph vertically to the turning point (1, 0).

4. The coefficient 1 makes the parabola open up; plot points one unit to either side of x = 1.

5. Answer: turning point (1, 0). Check: f(1) = 0, with symmetric points at x = 0 and x = 2.

Answer: (1, 0). Check: Answer: turning point (1, 0). Check: f(1) = 0, with symmetric points at x = 0 and x = 2.
