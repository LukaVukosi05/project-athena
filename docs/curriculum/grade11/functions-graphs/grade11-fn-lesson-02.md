Start with y = -2/x, which is undefined at x = 0 and approaches y = 0. Set the denominator to zero: x − 2 = 0, so x = 2 is excluded. Draw the vertical asymptote x = 2; translate the two branches around it. The vertical shift − 1 moves the horizontal asymptote to y = -1. Answer: x = 2; y = -1. Check: the denominator vanishes at x = 2 and f(x) approaches -1 for large |x|.
