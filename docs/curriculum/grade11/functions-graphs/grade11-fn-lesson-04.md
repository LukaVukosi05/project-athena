1. Plot the first point A = (1, f(1)) on the parabola.

2. Calculate f(1) = 0 and f(3) = 4, then plot B = (3, 4).

3. Draw the secant AB; its horizontal run is 3 − (1) = 2.

4. Its signed rise is 4 − (0) = 4; average gradient = (4)/2 = 2.

5. Answer: m = 2. Check: 2 × 2 = 4, the actual change in f.
