## g11-fn-l08-w01: For y = -3sin(2x), find its amplitude and period in degrees.

Visual values: `{"family": "grade11_functions", "values": {"mode": "trig_two", "fn": "sin", "a": -3, "k": 2, "period": 180}}`

1. Start with y = sin x and mark its original cycle 360°.

2. The factor 2 inside the function divides the cycle width by 2.

3. The coefficient -3 outside multiplies each ordinate by -3, including a reflection if negative.

4. The amplitude is 3 and the cycle width is 360/2 = 180°.

5. Answer: amplitude = 3; period = 180°. Check consecutive corresponding features are 180° apart.
