## g11-prob-l01-w01: A bag contains 3 red and 5 blue counters. A counter is drawn, replaced and the bag mixed 50 times; red occurs 18 times. Give theoretical P(red) and compare it with relative frequency.

Question-specific visual values: `{"family": "grade11_probability", "values": {"mode": "frequency", "red": 3, "blue": 5, "trials": 50, "observed": 18}}`

1. The bag has 3 + 5 = 8 equally likely counters.

2. There are 3 favourable red counters, so theoretical P(red) = 3/8.

3. Simplify the theoretical fraction to 3/8.

4. Experimental relative frequency is 18/50 = 0.360; replacement keeps the theoretical ratio fixed.

5. Answer: Theoretical P(red) = 3/8. Compare 0.375 with 0.360; experimental values can differ in a finite sample.

Answer: Theoretical P(red) = 3/8. Check: Answer: Theoretical P(red) = 3/8. Compare 0.375 with 0.360; experimental values can differ in a finite sample.
