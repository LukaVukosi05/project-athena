## g11-prob-l03-w01: Among 100 equally likely outcomes, 30 are in A, 50 in B and 15 in both. Decide whether A and B are independent.

Question-specific visual values: `{"family": "grade11_probability", "values": {"mode": "independence", "total": 100, "a": 30, "b": 50, "both": 15}}`

1. Use the same sample space of 100; P(A) = 30/100, P(B) = 50/100.

2. If independent, the product rule requires P(A and B) = 30/100 × 50/100 = 3/20.

3. The actual overlap is P(A and B) = 15/100 = 3/20.

4. Compare the actual joint probability to the product: 3/20 = 3/20.

5. Answer: Independent. The product rule holds; overlap alone does not imply independence.

Answer: Independent. Check: Answer: Independent. The product rule holds; overlap alone does not imply independence.

Use the same sample space of 500; P(A) = 250/500, P(B) = 200/500. If independent, the product rule requires P(A and B) = 250/500 × 200/500 = 1/5. The actual overlap is P(A and B) = 104/500 = 26/125. Compare the actual joint probability to the product: 26/125 ≠ 1/5. Answer: Dependent. The product rule does not hold; overlap alone does not imply independence.
