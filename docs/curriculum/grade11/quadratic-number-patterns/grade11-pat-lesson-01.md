## g11-pat-l01-w01: Consider the sequence 12, 15, 22, 33, 48, … . Determine whether it is quadratic using differences, then find T₆.

Visual givens: `{"family": "grade11_patterns", "values": {"mode": "difference", "terms": [12, 15, 22, 33, 48], "target": 8}}`

1. Write T₁ to T₅: 12, 15, 22, 33, 48. Keep each term in its given position.

2. Subtract adjacent terms: first differences are 3, 7, 11, 15. They are not constant.

3. Subtract adjacent first differences: 4, 4, 4. This is constant, so the pattern is quadratic.

4. Continue the first differences: 15 + 4 = 19; then T₆ = 48 + 19 = 67.

5. Answer: Quadratic; T₆ = 67. Check the final first difference is 19, and every second difference is 4.
