## g11-pat-l02-w01: Find the general term Tₙ = an² + bn + c for the sequence 12, 15, 22, 33, 48, … . Verify it at n = 4.

Visual givens: `{"family": "grade11_patterns", "values": {"mode": "rule", "terms": [12, 15, 22, 33, 48], "target": 8}}`

1. Write the five given terms in their positions: 12, 15, 22, 33, 48.

2. First differences: 3, 7, 11, 15; second differences: 4, 4, 4.

3. For a quadratic rule, constant second difference = 2a. Thus 2a = 4, so a = 2.

4. T₂ − T₁ = 3a + b = 3; b = 3 − 3(2) = -3. T₁ = a + b + c = 12, so c = 12 − (2) − (-3) = 13.

5. Answer: Tₙ = 2n² − 3n + 13. Check T₄ = 2(4²) + (-3)(4) + (13) = 33, matching the fourth given term.

Answer: Tₙ = 2n² − 3n + 13. Check: Answer: Tₙ = 2n² − 3n + 13. Check T₄ = 2(4²) + (-3)(4) + (13) = 33, matching the fourth given term.
