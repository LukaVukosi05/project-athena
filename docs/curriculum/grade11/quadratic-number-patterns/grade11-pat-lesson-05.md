## g11-pat-l05-w01: A learner sees 12, 15, 22, 33, 48, … and assumes the first difference stays at 3, predicting T8 = 33. Locate the first error and calculate the correct T8.

Visual givens: `{"family": "grade11_patterns", "values": {"mode": "diagnosis", "terms": [12, 15, 22, 33, 48], "target": 8}}`

1. Write adjacent differences from 12, 15, 22, 33, 48: 3, 7, 11, 15.

2. The first error is keeping 3 constant: the first differences change by 4 each time.

3. The second differences are 4, 4, 4, so a = 2. Using T₂ − T₁ = 3 gives b = -3, and T₁ = 12 gives c = 13.

4. Use the corrected rule Tₙ = 2n² − 3n + 13: T8 = 2(8²) + (-3)(8) + (13) = 117.

5. Answer: T8 = 117. The learner’s 33 used a linear rule; check the corrected rule reproduces T₁ = 12 and T₅ = 48.
