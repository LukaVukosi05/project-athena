1. Keep all six values [6, 9, 12, 15, 14, 20]; the population size is N = 6.

2. Calculate the unrounded mean: x̄ = 76/6 = 12.6667.

3. Subtract the mean and square each deviation; Σ(x − x̄)² = 119.3333.

4. Use population variance σ² = Σ(x − x̄)²/N = 119.3333/6 = 19.89.

5. Answer: Population variance = 19.89; standard deviation = 4.46. Check σ = √(19.8889) = 4.46; no N−1 sample correction.
