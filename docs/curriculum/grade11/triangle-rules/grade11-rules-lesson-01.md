## g11-rules-l01-w01: In ΔABC, draw altitude CD to AB. Derive a/sin A = b/sin B using a = BC and b = AC.

Visual values: `{"family": "grade11_triangle_rules", "values": {"mode": "proof_sine"}}`

1. Draw CD perpendicular to AB; label CD = h, BC = a and AC = b.

2. In right triangle ACD, sin A = h/b, so h = b sin A.

3. In right triangle BCD, sin B = h/a, so h = a sin B.

4. Equate the two heights: b sin A = a sin B; divide by sin A sin B.

5. Answer: a/sin A = b/sin B. Check both ratios equal ab/h for nondegenerate triangles.

Answer: a/sin A = b/sin B. Check: Answer: a/sin A = b/sin B. Check both ratios equal ab/h for nondegenerate triangles.

## g11-rules-l01-w02: In ΔABC, A = 40°, B = 70° and a = 8 cm. Find b to two decimal places.

Visual values: `{"family": "grade11_triangle_rules", "values": {"mode": "sine_side", "A": 40, "B": 70, "a": 8, "b": 11.695217600652349}}`

1. Label a = BC = 8 cm opposite A = 40°, and b = AC opposite B = 70°.

2. Draw an altitude to see the sine rule a/sin A = b/sin B.

3. Substitute: 8/sin(40°) = b/sin(70°).

4. Rearrange: b = 8 sin(70°)/sin(40°) = 11.70 cm.

5. Answer: b = 11.70 cm. Check: b sin(40°) and 8 sin(70°) agree before rounding.

Answer: b = 11.70 cm. Check: Answer: b = 11.70 cm. Check: b sin(40°) and 8 sin(70°) agree before rounding.
