Options: B = 42.00° or 145.00° | B = 42.00° or 138.00° | B = 42.00° only | B = 138.00° only. Correct: B = 42.00° or 138.00°. Label the known opposite pair A = 35°, a = 12 cm and second side b = 14 cm. By the sine rule, sin B = b sin A/a = 14 sin(35°)/12 = 0.6692. The acute branch is B₁ = arcsin(0.6692) = 42.00°. The supplementary branch is B₂ = 180° − 42.00° = 138.00°; both satisfy A + B < 180°. Answer: B = 42.00° or 138.00°. Check both sine values match 0.6692 before rounding.
