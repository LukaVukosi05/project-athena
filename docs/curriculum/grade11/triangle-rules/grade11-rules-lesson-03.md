## g11-rules-l03-w01: In ΔABC, place A at the origin and AB = c on the horizontal axis. Derive a² = b² + c² − 2bc cos A.

Visual values: `{"family": "grade11_triangle_rules", "values": {"mode": "proof_cosine"}}`

1. Draw AC = b making angle A with AB = c; lower perpendicular CD to AB.

2. The horizontal projection AD = b cos A, so DB = c − b cos A.

3. The vertical height CD = b sin A. Use Pythagoras: a² = (c − b cos A)² + (b sin A)².

4. Expand and combine b²(cos² A + sin² A) = b².

5. Answer: a² = b² + c² − 2bc cos A. Check A = 90° reduces to Pythagoras.

Answer: a² = b² + c² − 2bc cos A. Check: Answer: a² = b² + c² − 2bc cos A. Check A = 90° reduces to Pythagoras.

## g11-rules-l03-w02: In ΔABC, b = 7 cm and c = 11 cm enclose angle A = 60°. Find a to two decimals.

2. Drop a perpendicular from C to AB to see why the cosine rule uses the included angle.

4. Take the positive root: a = √(170 − 154 cos(60°)) = 9.64 cm.
