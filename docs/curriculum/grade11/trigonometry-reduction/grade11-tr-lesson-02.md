## g11-tr-l02-w01: Find the exact value of sin(90 − 30°).

Whiteboard values: `{"family": "grade11_trigonometry", "values": {"mode": "reduction", "theta": 60, "reference": 30, "function": "sin", "quadrant": 1}}`

1. Read the angle in degrees: 90 − 30° = 60°. Reduce it modulo 360° if necessary.

2. Its terminal arm lies in quadrant 1. The acute reference angle is 30°.

3. The sin ratio is positive in quadrant 1.

4. The reference magnitude is cos(30°) = √3/2; apply the quadrant sign.

5. Answer: sin(90 − 30°) = √3/2. Its exact sign and reference ratio agree with the unit circle.

Answer: √3/2. Verification: Answer: sin(90 − 30°) = √3/2. Its exact sign and reference ratio agree with the unit circle.
