## g11-tr-l03-w01: Find the exact value of sin(180 − 30°).

Whiteboard values: `{"family": "grade11_trigonometry", "values": {"mode": "reduction", "theta": 150, "reference": 30, "function": "sin", "quadrant": 2}}`

1. Read the angle in degrees: 180 − 30° = 150°. Reduce it modulo 360° if necessary.

2. Its terminal arm lies in quadrant 2. The acute reference angle is 30°.

3. The sin ratio is positive in quadrant 2.

4. The reference magnitude is sin(30°) = 1/2; apply the quadrant sign.

5. Answer: sin(180 − 30°) = 1/2. Its exact sign and reference ratio agree with the unit circle.

Answer: 1/2. Verification: Answer: sin(180 − 30°) = 1/2. Its exact sign and reference ratio agree with the unit circle.
