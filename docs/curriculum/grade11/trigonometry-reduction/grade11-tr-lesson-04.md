## g11-tr-l04-w01: Find the exact value of sin(360 − 30°).

Whiteboard values: `{"family": "grade11_trigonometry", "values": {"mode": "reduction", "theta": 330, "reference": 30, "function": "sin", "quadrant": 4}}`

1. Read the angle in degrees: 360 − 30° = 330°. Reduce it modulo 360° if necessary.

2. Its terminal arm lies in quadrant 4. The acute reference angle is 30°.

3. The sin ratio is negative in quadrant 4.

4. The reference magnitude is sin(30°) = 1/2; apply the quadrant sign.

5. Answer: sin(360 − 30°) = -1/2. Its exact sign and reference ratio agree with the unit circle.

Answer: -1/2. Verification: Answer: sin(360 − 30°) = -1/2. Its exact sign and reference ratio agree with the unit circle.
