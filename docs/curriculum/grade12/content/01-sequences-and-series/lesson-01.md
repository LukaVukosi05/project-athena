# Recognising sequence structure

## Learning objective

Classify arithmetic, geometric and quadratic patterns using evidence, not appearance.

## Prerequisite diagnostic

Check the prerequisite concepts listed in the source teaching sequence before beginning the worked examples.

## Full concept explanation

A sequence is an ordered list. The position is n and the value at that position is T_n. Arithmetic sequences have a constant first difference. Geometric sequences have a constant non-zero ratio. Quadratic patterns have constant second differences. A pattern must be tested before a rule is chosen.

## Vocabulary and notation

Use the notation and mathematical vocabulary introduced in the concept explanation exactly as written.

## Whiteboard teaching sequence

- Frame
- Board state / animation
- Teacher narration or prompt
- 1
- Display 5, 9, 13, 17, … with positions 1–4.
- Ask what changes from term to term.
- 2
- Draw first-difference row: +4, +4, +4. Highlight equality.
- Constant first difference means arithmetic.
- 3
- Display 3, 6, 12, 24, … and calculate 6/3, 12/6, 24/12.
- Constant ratio 2 means geometric.
- 4
- Display 2, 6, 12, 20, …; first differences 4, 6, 8; second differences 2, 2.
- Constant second difference signals a quadratic pattern.
- 5
- Show decision flow: differences → ratios → second differences.
- Classification comes from a test, not a guess.

## Worked examples

- Question: Classify 18, 13, 8, 3, …
- Worked answer: Differences are −5, −5, −5, so it is arithmetic with d = −5.
- Question: Classify 81, 27, 9, 3, …
- Worked answer: Ratios are 1/3, 1/3, 1/3, so it is geometric with r = 1/3.
- Misconception repair  A learner sees numbers increasing and calls the sequence arithmetic. Repair: increasing only describes direction; constant difference proves arithmetic.
