# Arithmetic sequences in context

## Learning objective

Model constant additive change and interpret variables with units.

## Prerequisite diagnostic

Check the prerequisite concepts listed in the source teaching sequence before beginning the worked examples.

## Full concept explanation

An arithmetic model is appropriate when the quantity changes by the same amount per equal interval. Define what n=1 represents. Units and starting position determine a; careless indexing changes the whole model.

## Vocabulary and notation

Use the notation and mathematical vocabulary introduced in the concept explanation exactly as written.

## Whiteboard teaching sequence

- Frame
- Board state / animation
- Teacher narration or prompt
- 1
- Scenario: hall row 1 has 18 seats; each next row has 3 more.
- Identify constant additive change.
- 2
- Create table n:1,2,3 and seats:18,21,24.
- Anchor the first term explicitly.
- 3
- Write T_n=18+3(n−1).
- Connect table, words and formula.
- 4
- Find row 25: 18+24(3)=90.
- Interpret the numerical result with units.
- 5
- Ask whether 100 seats occurs: solve 18+3(n−1)=100.
- A non-integer n means no row has exactly that number.

## Worked examples

- Question: A runner adds 0.4 km to a 3 km first training run each day. Distance on day 15?
- Worked answer: 3+14(0.4)=8.6 km.
- Question: A tank loses 12 L each hour from 500 L at the end of hour 1. Amount at end of hour 18?
- Worked answer: 500+17(−12)=296 L.
- Misconception repair  Treating the initial amount at time 0 as T_1 without checking the wording. Repair: state the meaning of n=1 before choosing a.
