# Quadratic number patterns

## Learning objective

Find T_n=an²+bn+c from constant second differences.

## Prerequisite diagnostic

Check the prerequisite concepts listed in the source teaching sequence before beginning the worked examples.

## Full concept explanation

For T_n=an²+bn+c, the constant second difference equals 2a. After finding a, substitute known terms to find b and c. The method links a difference table to the algebraic rule.

## Vocabulary and notation

Use the notation and mathematical vocabulary introduced in the concept explanation exactly as written.

## Whiteboard teaching sequence

- Frame
- Board state / animation
- Teacher narration or prompt
- 1
- Display 3,8,15,24,… with positions.
- Create first differences 5,7,9.
- 2
- Create second differences 2,2. Highlight constant 2.
- Therefore 2a=2 and a=1.
- 3
- Write T_n=n²+bn+c.
- Use the leading coefficient immediately.
- 4
- Use n=1 and n=2: 1+b+c=3; 4+2b+c=8.
- Known terms create linear equations.
- 5
- Solve b=2,c=0; T_n=n²+2n; verify n=3.
- Verification closes the loop.

## Worked examples

- Question: Find T_n for 3,8,15,24,…
- Worked answer: T_n=n²+2n.
- Question: Find T_20 for 2,9,20,35,…
- Worked answer: Second diff 4→a=2; rule 2n²+n−1; T_20=819.
- Misconception repair  Setting a equal to the second difference. Repair: second difference is 2a.
