# Finite geometric-series applications

## Learning objective

Use finite sums for repeated multiplicative contributions.

## Prerequisite diagnostic

Check the prerequisite concepts listed in the source teaching sequence before beginning the worked examples.

## Full concept explanation

Finite geometric models appear when each contribution is a constant multiple of the previous one: bounces, staged payments, viral sharing and shrinking lengths. Define whether the initial quantity is term 1 and count exactly how many contributions occur.

## Vocabulary and notation

Use the notation and mathematical vocabulary introduced in the concept explanation exactly as written.

## Whiteboard teaching sequence

- Frame
- Board state / animation
- Teacher narration or prompt
- 1
- Ball dropped 8 m; each rebound is 3/4 previous height. Find upward distance over 5 rebounds.
- List rebound heights only: 6,4.5,…
- 2
- Set a=6,r=0.75,n=5.
- The drop height is not the first rebound term.
- 3
- Use finite sum S_5=6[1−0.75^5]/0.25.
- Sum upward distances.
- 4
- Evaluate ≈18.305 m upward.
- Round only at the end.
- 5
- If total travel is asked, add downward segments appropriately.
- Model wording controls which distances are included.

## Worked examples

- Question: A prize pays R1 000 in round 1 and doubles for 8 rounds. Total?
- Worked answer: 1 000(2^8−1)=R255 000.
- Question: A fractal line uses lengths 81,27,9,3 for four stages. Total?
- Worked answer: 120 units.
- Misconception repair  Automatically including the initial amount in a series that begins after an event. Repair: write the first three physical contributions before selecting a.
