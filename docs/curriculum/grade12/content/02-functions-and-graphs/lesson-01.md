## Teach the idea

A function assigns each allowed input exactly one output. f(x) is the output produced by input x; it does not mean f multiplied by x. Domain describes allowed inputs and range describes resulting outputs.

## Worked examples

Question: For f(x)=x²−4, find f(−3).

Worked answer: f(−3)=(−3)²−4=5.

Question: If g(x)=3x+1 and g(x)=19, find x.

Worked answer: 3x+1=19, therefore x=6.

Misconception repair  Confusing f(3) with 3f. Repair by replacing every x with brackets containing 3.
