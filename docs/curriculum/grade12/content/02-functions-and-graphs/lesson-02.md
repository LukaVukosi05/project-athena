## Teach the idea

Graph analysis begins with domain, range, intercepts, turning points and asymptotes. Read coordinates as ordered pairs and distinguish an x-intercept, where y=0, from a y-intercept, where x=0.

## Whiteboard sequence

| Frame | Board state and animation | Narration / learner action |
| --- | --- | --- |
| 1 | Display a parabola and label axes and scale. | Explain, predict, calculate or verify this change before continuing. |
| 2 | Highlight x-intercepts and set y=0 in the equation. | Explain, predict, calculate or verify this change before continuing. |
| 3 | Highlight the y-intercept and set x=0. | Explain, predict, calculate or verify this change before continuing. |
| 4 | Mark the turning point and describe minimum/maximum. | Explain, predict, calculate or verify this change before continuing. |
| 5 | Write domain and range using inequalities or interval language. | Explain, predict, calculate or verify this change before continuing. |

## Worked examples

Question: For y=x²−5x+6, find intercepts.

Worked answer: x-intercepts (2,0),(3,0); y-intercept (0,6).

Question: For y=(x−2)²−4, state range.

Worked answer: Minimum y=−4, so y≥−4.

Misconception repair  Swapping intercept procedures. Repair: x-intercept lies on x-axis, so its y-coordinate is zero.
