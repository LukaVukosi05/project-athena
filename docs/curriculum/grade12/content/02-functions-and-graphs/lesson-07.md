## Mastery objective

Analyse y=ab^(x−p)+q and distinguish growth from decay.

Duration: 50–65 minutes

Mastery objective: Analyse y=ab^(x−p)+q and distinguish growth from decay.

Stable lesson ID: g12-functions-07

Mastery threshold: 80% with targeted remediation

## Teach the idea

For b>1 the parent function grows; for 0<b<1 it decays. The horizontal asymptote is y=q. The exponential expression itself is positive, so the sign of a controls which side of the asymptote contains the graph.

## Worked examples

Question: Analyse y=3(1/2)^x−2.

Worked answer: Decay; asymptote y=−2; domain all real; range y>−2.

Question: Solve graphically 2^x=8.

Worked answer: Intersection gives x=3.

Misconception repair  Calling a graph decay because it falls below the x-axis. Repair: growth/decay refers to base b, while a controls reflection.
