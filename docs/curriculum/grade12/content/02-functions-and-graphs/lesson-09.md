## Mastery objective

Find inverses, state restrictions and distinguish f^−1(x) from 1/f(x).

Duration: 50–65 minutes

## Teach the idea

An inverse reverses input and output. Swap x and y, then solve for y. A function has an inverse function only when it is one-to-one on its stated domain; otherwise restrict the domain.

## Worked examples

Question: Find inverse of f(x)=2x+7.

Worked answer: f^−1(x)=(x−7)/2.

Question: Why does f(x)=x² need restriction?

Worked answer: Both x and −x give the same output; restrict e.g. x≥0.

Misconception repair  Writing f^−1(x)=1/f(x). Repair: reciprocal changes outputs; inverse swaps input and output.
