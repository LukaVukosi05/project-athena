## Mastery objective

Predict and explain translations, reflections and stretches.

Duration: 50–65 minutes

Mastery objective: Predict and explain translations, reflections and stretches.

Stable lesson ID: g12-functions-11

Mastery threshold: 80% with targeted remediation

## Teach the idea

In y=af(b(x−p))+q, outside changes affect outputs and inside changes affect inputs. Horizontal changes appear with the opposite sign when solving the inside expression.

## Whiteboard sequence

| Frame | Board state and animation | Narration / learner action |
| --- | --- | --- |
| 1 | Plot parent f(x)=x². | Explain, predict, calculate or verify this change before continuing. |
| 2 | Add q=3 and move every point up 3. | Explain, predict, calculate or verify this change before continuing. |
| 3 | Use f(x−2) and move points right 2. | Explain, predict, calculate or verify this change before continuing. |
| 4 | Use −f(x) for reflection in x-axis. | Explain, predict, calculate or verify this change before continuing. |
| 5 | Use f(−x) for reflection in y-axis and compare. | Explain, predict, calculate or verify this change before continuing. |

## Worked examples

Question: Describe y=−2(x+3)²+5 from y=x².

Worked answer: Left 3, vertical stretch 2, reflect in x-axis, up 5.

Question: Describe y=3^(x−4)−2.

Worked answer: Right 4 and down 2.

Misconception repair  Reading x+3 as right 3. Repair: set x+3=0; the reference input occurs at x=−3.
