## Mastery objective

Solve intersections algebraically and interpret them graphically.

Duration: 50–65 minutes

Mastery objective: Solve intersections algebraically and interpret them graphically.

Stable lesson ID: g12-functions-12

Mastery threshold: 80% with targeted remediation

## Teach the idea

At an intersection, both functions have the same x and y. Set their expressions equal, solve allowable x-values, then substitute for y. The number of real solutions matches the number of visible intersections.

## Whiteboard sequence

| Frame | Board state and animation | Narration / learner action |
| --- | --- | --- |
| 1 | Overlay y=x²−4 and y=2x. | Explain, predict, calculate or verify this change before continuing. |
| 2 | Set x²−4=2x. | Explain, predict, calculate or verify this change before continuing. |
| 3 | Rearrange x²−2x−4=0 and solve exactly. | Explain, predict, calculate or verify this change before continuing. |
| 4 | Substitute each x into y=2x. | Explain, predict, calculate or verify this change before continuing. |
| 5 | Highlight both intersection coordinates and verify. | Explain, predict, calculate or verify this change before continuing. |

## Worked examples

Question: Intersect y=x² and y=3x+4.

Worked answer: x=4 or −1; points (4,16),(−1,1).

Question: Intersect y=2^x and y=4.

Worked answer: x=2; point (2,4).

Misconception repair  Reporting only x-values when coordinates are asked. Repair: substitute each solution to obtain y.
