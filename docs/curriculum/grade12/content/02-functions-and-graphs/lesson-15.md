## Mastery objective

Determine unknown function parameters from features and points.

Duration: 50–65 minutes

Mastery objective: Determine unknown function parameters from features and points.

Stable lesson ID: g12-functions-15

Mastery threshold: 80% with targeted remediation

## Teach the idea

Parameters encode geometry. Use asymptotes, roots, turning points and supplied coordinates to select a form and solve unknown constants. Keep domain restrictions visible throughout.

| Frame | Board state and animation | Narration / learner action |

## Worked examples

Question: Exponential asymptote y=2, point (0,5), base 3.

Worked answer: y=3·3^x+2.

Question: Parabola roots −2,6 and y-intercept 12.

Worked answer: y=−(x+2)(x−6).

Misconception repair  Using every supplied number as a parameter without checking its meaning. Repair: translate each feature into an equation or form choice.
