## Mastery objective

Diagnose and repair common graph and inverse-function mistakes.

Duration: 50–65 minutes

Mastery objective: Diagnose and repair common graph and inverse-function mistakes.

Stable lesson ID: g12-functions-17

Mastery threshold: 80% with targeted remediation

## Teach the idea

Error analysis identifies the first invalid step, the concept violated and the corrected reasoning. A plausible graph is not evidence unless its defining features agree with the equation.

## Whiteboard sequence

| Frame | Board state and animation | Narration / learner action |
| --- | --- | --- |
| 1 | Show incorrect vertex (3,2) for (x+3)²+2. | Explain, predict, calculate or verify this change before continuing. |
| 2 | Use inside-zero reasoning to correct x=−3. | Explain, predict, calculate or verify this change before continuing. |
| 3 | Show inverse 1/(2x+5) for f=2x+5. | Explain, predict, calculate or verify this change before continuing. |
| 4 | Swap x,y and solve to get (x−5)/2. | Explain, predict, calculate or verify this change before continuing. |
| 5 | Show range y≥4 for −(x−1)²+4 and correct to y≤4. | Explain, predict, calculate or verify this change before continuing. |

## Worked examples

Question: Repair domain “all real” for 1/(x−7).

Worked answer: x≠7.

Question: Repair “2^x has y-intercept 0”.

Worked answer: At x=0, y=1.

Misconception repair  Trusting visual appearance over exact features. Repair: check intercepts, asymptotes, vertex and one additional point.

## Independent practice and answer check

| Question | Answer / expected conclusion |
| --- | --- |
| Error: inverse point (2,5) stays (2,5) | It becomes (5,2) |
| Error: x²−4≥0 gives −2≤x≤2 | Correct: x≤−2 or x≥2 |
| Error: log domain includes zero | Log input must be positive |
| Minimum graph checks | Features plus at least one point |
