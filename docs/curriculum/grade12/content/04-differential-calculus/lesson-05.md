## Mastery objective

Use numerical and graphical evidence to explain what it means for a quantity to approach a value.

Duration: 50-70 minutes

Stable lesson ID: g12-calculus-05

Mastery objective: Use numerical and graphical evidence to explain what it means for a quantity to approach a value.

Mastery threshold: 80% with conceptual explanation required

## Teach the idea before the formula

A limit describes the value an expression approaches near an input, even when direct substitution at that input is initially impossible. It is about nearby behaviour.

Formula anchor  limit as h approaches 0 of L(h) = L, when nearby L(h) values approach L.

Where it comes from and why it works  First-principles quotients often contain a factor h in both numerator and denominator. For h not equal to zero it can be cancelled, giving an equivalent nearby expression whose approaching value is visible.

## Formula-understanding checkpoint

| Learner must answer | Evidence of understanding |
| --- | --- |
| What does the formula measure? | Names the mathematical object or contextual rate, not only the symbols. |
| What does each part mean? | Connects the numerator, denominator, derivative level, condition or parameter to the visual model. |
| Why is the operation valid? | States the algebraic, graphical or domain reason. |
| When would this formula be wrong? | Identifies a mismatched target, missing condition or invalid interpretation. |

## Whiteboard reasoning sequence

| Frame | Board state and animation | Narration / learner action |
| --- | --- | --- |
| 1 | Create a table of positive and negative h-values. | Orient: name the target quantity and what is known. |
| 2 | Calculate the corresponding expression values. | Inspect: connect symbols to graph objects or changing quantities. |
| 3 | Move h closer to zero from both sides. | Operate: show the cause before the changed expression. |
| 4 | Highlight the common approached value. | Explain: state why the transition is mathematically valid. |
| 5 | Distinguish 'approaches' from 'equals at'. | Verify: check direction, units, coordinates, signs or boundaries. |

## Worked examples

Question: Evaluate the approaching value of [(2+h)^2-4]/h.

Worked reasoning: For h not equal to zero it simplifies to 4+h, which approaches 4.

Question: Why use h=-0.1 as well as h=0.1?

Worked reasoning: It checks approach from both sides of zero.

Misconception repair  Treating a limit as permission to divide by zero. Repair by showing equivalence only for nearby non-zero h.

## Progressive support

| Support stage | Learner-facing action |
| --- | --- |
| Hint 1 - target | State what the question is asking for: output, average rate, derivative, tangent, stationary point, concavity, optimum or contextual rate. |
| Hint 2 - structure | Draw or inspect the graph/model. Name the relevant formula or condition and explain every symbol before substitution. |
| Hint 3 - first valid step | Show the first algebraic operation only. Keep signs, brackets and domain conditions visible. |

## Detailed worked-solution presentation

- Begin with a one-sentence target statement: 'I need to find ...'.

- Reveal the formula's visual meaning before using its compressed symbolic form.

- Give each algebraic line a plain-language 'Why?' explanation.

- Highlight the first invalid step when repairing an attempt rather than only showing the final memo.

- Finish with an independent verification: graph behaviour, substitution, sign analysis, units, domain or boundary comparison.

Explain-back exit checkpoint  The learner must explain why the formula or derivative condition applies here. A correct answer with no explanation is recorded as supported procedural success, not yet independent conceptual mastery.
