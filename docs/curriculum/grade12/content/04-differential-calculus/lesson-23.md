## Teach the idea before the formula

Exam mastery means selecting a reasoning chain from unfamiliar wording. The learner should first identify the demanded object: gradient, tangent, stationary point, graph feature, optimum or contextual rate.

Formula anchor  Decision map: demanded object -> derivative level -> equation/condition -> solve -> verify -> interpret.

Where it comes from and why it works  Different question forms reuse a small number of principles. Mapping the wording to the correct mathematical object prevents formula guessing.

## Formula-understanding checkpoint

| Learner must answer | Evidence of understanding |
| --- | --- |
| What does the formula measure? | Names the mathematical object or contextual rate, not only the symbols. |
| What does each part mean? | Connects the numerator, denominator, derivative level, condition or parameter to the visual model. |
| Why is the operation valid? | States the algebraic, graphical or domain reason. |
| When would this formula be wrong? | Identifies a mismatched target, missing condition or invalid interpretation. |

## Whiteboard reasoning sequence

| Frame | Board state and animation | Narration / learner action |
| --- | --- | --- |
| 1 | Annotate command words and supplied information. | Orient: name the target quantity and what is known. |
| 2 | Choose f, f' or f'' and explain why. | Inspect: connect symbols to graph objects or changing quantities. |
| 3 | Write the required condition before substituting. | Operate: show the cause before the changed expression. |
| 4 | Solve with method marks visible. | Explain: state why the transition is mathematically valid. |
| 5 | Check graph sense, domain, units and conclusion. | Verify: check direction, units, coordinates, signs or boundaries. |

## Worked examples

Question: Given a cubic graph and one stationary coordinate, determine missing parameters.

Worked reasoning: Translate the stationary coordinate into both f(a)=b and f'(a)=0, then solve the simultaneous conditions.

Question: Optimisation item with a composite solid.

Worked reasoning: Select the supplied geometry formula, reduce to one variable, differentiate, classify and interpret.

Misconception repair  Choosing a formula from a keyword without defining the target quantity. Repair by requiring a one-sentence 'I need to find...' statement.

| Question | Answer / expected conclusion |
| --- | --- |
| Tangent gradient requires | f'(a) |
| Stationary point requires | f'(x)=0 |
| Inflection proof requires | f'' sign change |
| Optimisation requires | Model, domain, classification and interpretation |

## Progressive support

| Support stage | Learner-facing action |
| --- | --- |
| Hint 1 - target | State what the question is asking for: output, average rate, derivative, tangent, stationary point, concavity, optimum or contextual rate. |
| Hint 2 - structure | Draw or inspect the graph/model. Name the relevant formula or condition and explain every symbol before substitution. |
| Hint 3 - first valid step | Show the first algebraic operation only. Keep signs, brackets and domain conditions visible. |

## Detailed worked-solution presentation

- Begin with a one-sentence target statement: 'I need to find ...'.

- Reveal the formula's visual meaning before using its compressed symbolic form.

- Give each algebraic line a plain-language 'Why?' explanation.

- Highlight the first invalid step when repairing an attempt rather than only showing the final memo.

- Finish with an independent verification: graph behaviour, substitution, sign analysis, units, domain or boundary comparison.

Explain-back exit checkpoint  The learner must explain why the formula or derivative condition applies here. A correct answer with no explanation is recorded as supported procedural success, not yet independent conceptual mastery.
