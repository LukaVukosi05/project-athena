## Question-first whiteboard examples

### g8-frac-l01-w01
Question: Do 2/3 and 6/9 name the same part of a whole?
Visual: same-sized fraction strips for 2/3, 6/9. Start with given partitions; repartition to the common unit, then reveal calculation and check.
1. Split both same-sized wholes into 3 equal pieces.
2. Rewrite 2/3 as 2/3 and 6/9 as 2/3.
3. The numerators 2 and 2 match; the claim is yes.
Answer: yes.
Memo: Do 2/3 and 6/9 name the same part of a whole? The common unit is 3; scaled counts are [2, 2]. Answer: yes.
Misconception repair: Use equal-sized wholes and multiply numerator and denominator together; never compare only the bottom numbers.
