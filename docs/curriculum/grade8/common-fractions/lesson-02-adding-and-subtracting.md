## Question-first whiteboard examples

### g8-frac-l02-w01
Question: Calculate 1/4 + 2/4.
Visual: same-sized fraction strips for 1/4, 2/4. Start with given partitions; repartition to the common unit, then reveal calculation and check.
1. Draw the original fraction quantities with the same-sized unit.
2. Repartition each unit into 4 equal parts; convert the numerators to 1, 2.
3. Compute (1 + 2)/4 = 3/4; simplify to 3/4.
Answer: 3/4.
Memo: LCD 4. Numerators in operation order: 1 + 2. Result 3/4 = 3/4. Recombine to check the original quantities.
Misconception repair: Never add denominators; use equivalent fractions and apply subtraction to the whole numerator of the second term.
