# Grade 8 Decimal Fractions Lesson 1: Place value, ordering and comparing decimals

Original Athena examples. Curriculum scope: 2026 DBE Grade 8 Mathematics ATP, Term 1 (https://www.education.gov.za/Portals/0/Documents/Recovery%20plan%20page/2026%20ATPs/2026_ATP_Mathematics_Grade%208.pdf?ver=2026-01-20-202040-113). Questions and worked explanations are original rather than reproduced from the ATP. Teacher review required.

A learner sees the question first. Digit columns, equal place values and number-line marks appear one operation at a time. The final answer is hidden until verification.

## Worked example 1: In 4.307, what digit is in the tenths place?
Whiteboard: Build digit columns for 4.307; highlight the tenths column and show its digit. Hold each prior mathematical state on the board.
1. Align 4.307 in ones, tenths, hundredths and thousandths columns.
2. Count 1 position(s) to the right of the decimal point.
3. The digit in the tenths column is 3.
Answer (revealed after reasoning): 3
Check: Read the digits of 4.307 again from the decimal point; the tenths column contains 3.

## Worked example 9: Order 0.8, 0.08 and 0.808 from least to greatest.
Whiteboard: Align 0.8, 0.08, 0.808 at the decimal point. Compare the first unequal column, then place all markers on a number line. Hold each prior mathematical state on the board.
1. Align all decimal points and pad with zeroes to 3 decimal places.
2. Compare columns from left to right, then place the three numbers on one number line.
3. From left to right: 0.08, 0.8, 0.808.
Answer (revealed after reasoning): 0.08, 0.8, 0.808
Check: The ordered values satisfy 0.08 < 0.8 < 0.808.
