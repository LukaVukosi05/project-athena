# Lesson 5: Squares and cubes of decimal fractions

Grade 8 Mathematics · Decimal Fractions · CAPS 2026 ATP. Original authored examples; no past-paper text reproduced.

## Objective
Show each factor or root test, track the decimal scale, and verify the answer using the original value.

## Before you begin
Recall multiplying decimals, repeated multiplication, decimal place value and the difference between a square and a cube.

## Teaching rule
A power repeats a factor; a principal root reverses a power and has a non-negative answer. Estimate before calculating, then check against the given value.

## Whiteboard contract
Present the entire question first. The final answer is concealed. For each question: highlight the base or radicand, reveal one operation, retain all earlier operations in the worked solution, and show the inverse check only at the end. Replay and Previous reconstruct the same stage. No auto-generated math is permitted in the learner view.

## Worked examples

### Example 1 · Foundation
**Question.** Calculate (0.2)^2. Show the repeated factors and decimal scale.
**Answer.** 0.04
**Worked memo.**
1. Identify the base 0.2 and the exponent 2; a square repeats the same factor 2 times.
2. Expand the power: (0.2)^2 = 0.2 × 0.2.
3. Each factor has 1 decimal place(s), so the product has 2 × 1 = 2 decimal places before removing trailing zeros.
4. Compute the integer product: 2 × 2 = 4.
5. Place the decimal point 2 positions from the right: 0.04.
**Verification.** 0.2 × 0.2 = 0.04; repeated multiplication checks the original power.
**Misconception repair.** Do not multiply the base by the exponent; show repeated equal factors.
