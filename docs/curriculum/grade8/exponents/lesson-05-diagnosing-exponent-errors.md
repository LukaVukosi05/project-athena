# Grade 8 Exponents · Lesson 5: Diagnosing exponent errors

Scope: 2026 DBE Grade 8 Mathematics ATP. All questions are original; teacher review pending.

**Objective:** Identify the first incorrect exponent or root operation, repair it, and verify the original expression.

Each example begins with a complete question. The answer and memo are gated. The whiteboard shows a question-specific claim/operation trace or measured model; it reveals one line and its mathematical object at a time, retaining previous lines. Independent practice and assessment use unseen values.

## Worked example 1 · foundation

**Question:** A learner says (−3)² = −9. Locate the first sign error and find the correct value.

**Whiteboard:** exponent_error_trace with values 3, 2.

**Narrated mathematical actions:**

1. The brackets include −3 in every one of the 2 factors.
2. Expand (−3)² into (−3) × (−3).
3. Pair the 2 negative signs: every pair produces a positive sign.
4. Multiply the magnitudes: 3² = 9.
5. The first error is treating a bracketed negative base as an outside minus; the correct value is 9.

**Answer after teaching:** 9
**Verification:** (−3) × (−3) = 9; the learner’s −9 is not equal.
**Misconception repair:** Include the minus sign in every bracketed factor; even negative factor counts give a positive value.

## Worked example 2 · easy

**Question:** A learner claims √64 gives both a positive and a negative answer. What single value does √64 represent?

**Whiteboard:** exponent_error_trace with values 64.

**Narrated mathematical actions:**

1. The symbol √64 means the principal, nonnegative square root.
2. Draw 64 unit squares as a 8 by 8 square.
3. 8² = 64; this verifies the side length 8.
4. Although (−8)² = 64, the symbol √ chooses the nonnegative value.
5. So √64 = 8, not a two-value answer.

**Answer after teaching:** 8
**Verification:** 8² = 64 and 8 ≥ 0; √64 = 8.
**Misconception repair:** The √ symbol denotes the nonnegative principal root; solving x²=n is a different question.

## Worked example 3 · easy

**Question:** A learner uses addition of exponents for 5⁴ ÷ 5². Show the first incorrect law and give the correct value.

**Whiteboard:** exponent_error_trace with values 5, 4, 2.

**Narrated mathematical actions:**

1. Identify the nonzero common base 5 and the division sign.
2. Write 4 factors of 5 in the numerator and 2 in the denominator.
3. Cancel 2 equal nonzero pairs, leaving 2 numerator factors.
4. Division requires subtracting exponents: 4 − 2 = 2.
5. Evaluate 5² = 25; adding exponents was the first wrong law.

**Answer after teaching:** 25
**Verification:** 625 ÷ 25 = 25; direct division confirms the quotient.
**Misconception repair:** Division of powers with the same nonzero base subtracts exponents after factor cancellation.

## Worked example 4 · standard

**Question:** A learner replaces √25 + √49 with √(25 + 49). Find the first incorrect step and evaluate the original expression.

**Whiteboard:** exponent_error_trace with values 25, 49.

**Narrated mathematical actions:**

1. A plus sign separates two roots. Keep √25 and √49 as separate terms.
2. Build a square from 25 tiles: √25 = 5.
3. Build a second square from 49 tiles: √49 = 7.
4. Now add their side values: 5 + 7 = 12.
5. The first error was moving addition inside one square root; the original expression equals 12.

**Answer after teaching:** 12
**Verification:** 5² = 25, 7² = 49, and 5 + 7 = 12.
**Misconception repair:** The square root does not distribute across addition; find each exact root separately.

## Worked example 5 · standard

**Question:** A learner multiplies the exponents in 2² × 2³ + √81. Locate the first error and evaluate the expression.

**Whiteboard:** exponent_error_trace with values 2, 2, 3, 81.

**Narrated mathematical actions:**

1. Keep the multiplication of the two powers separate from the added root.
2. The powers have common base 2: write 2 factors and another 3 factors.
3. Count 2+3=5 equal factors, so the product is 2⁵.
4. Evaluate 2⁵ = 32.
5. Evaluate √81 = 9, because 9² = 81.
6. Add 32 + 9 = 41. Multiplying the exponents was the first error.

**Answer after teaching:** 41
**Verification:** (4 × 8) + 9 = 41; direct values agree.
**Misconception repair:** The product law adds exponents for the same base; then evaluate the separate root.
