This pack specifies individual mathematical states and visual objects. The board starts with the question and givens, shows an operation before its value, keeps prior work visible and checks the original.

## Worked examples

### 01 — foundation (2 marks)

**Question:** Words say double an input then add 1. Does y=2x+1 or y=2(x+1) match? Test x=2.
**Answer:** 2x+1; at x=2, y=5
**Question scene:** {"input": 2, "candidates": [{"label": "2x+1", "value": 5, "a": 0, "b": 2, "c": 1}, {"label": "2(x+1)", "value": 6, "a": 0, "b": 2, "c": 2}], "chosen": "2x+1", "given": ["double, then add 1", "y=2x+1", "y=2(x+1)"], "mode": "match"}
**Board states:** Read the given representations → Test input 2 in both rules → 2x+1 → 5; 2(x+1) → 6 → 2x+1; at x=2, y=5
- Identify what is fixed and what changes. Narration/caption: At input 2, substitute in each candidate, keeping the original operation order.
- Evaluate both candidates at input 2. Narration/caption: The candidates give 5 and 6. Compare with the stated relationship.
- Choose 2x+1 and state the output. Narration/caption: 2x+1; at x=2, y=5. Read the input and output with the context units, if any.
**Verification:** At input 2, 2x+1 gives 5; recheck against the original words, rows or formula.
**Misconception:** Grouping the +1 inside the doubling.
**Targeted repair:** Perform the operations in the spoken order.
