# Lesson 3: Mixed angle diagrams

Objective: select two justified angle relationships in one diagram, carry the intermediate value into the second calculation, and check the original given. All fifteen authored cases vary the marked sectors and values. Start with corresponding and straight-line pairs, continue through alternate interior and straight-line pairs, and end with co-interior and vertically opposite pairs. Learners must name both reasons. The renderer exposes the intermediate angle before the target. The final five cases require distinguishing a supplementary pair from a vertical pair.

Independent practice changes the given angles. Mastery uses five further values; failed items route to a highlighted theorem repair and parallel reassessment. Do not infer equality from the shape's appearance.

## Authored question bank

Each whiteboard example shows the problem, marked parallel lines and a visible first angle. The intermediate angle is concealed until its relationship is explained. The second angle and final answer appear only after their own mathematical steps. Previous results persist in the written solution.

### Worked example 1: g8-lines-03-w01
Two parallel lines are cut by a transversal. The upper marked angle is 43°. The marked pair is corresponding. An angle beside the lower marked angle is labelled x. Find the angle x and justify both angle steps.

Diagram: corresponding_linear; given 43°, first intermediate sector 43°, target sector 137°; initial target label x.
Whiteboard sequence:

1. Locate the two marked parallel lines and transversal; read the given 43° angle.
2. Identify the corresponding angle pair before calculating.
3. Corresponding angles are equal, so the lower marked angle is 43°.
4. Adjacent angles on a straight line add to 180°, so the target angle is 180° − 43° = 137°.
5. Therefore x = 137°.

Answer: 137°. Check: The transferred angle is 43°; 43° + 137° = 180°.
Misconception: Use the named angle theorem, then the second relationship; do not measure the picture.
