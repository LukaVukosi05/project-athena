# Lesson 5: First-error angle diagnosis and repair

Objective: inspect a learner's proposed angle relationship, identify the first unsupported claim using line markings, replace it with the correct theorem, complete the two-step chain and verify. Do not reveal the repaired answer before the attempted claim appears. Fifteen changed diagrams and claims cover corresponding, alternate and co-interior relations. The SVG keeps the given, intermediate and target sectors visible while the incorrect claim is marked only in its diagnostic stage.

Independent practice, five-item mastery and three changed reassessment items are separate from the teaching cases. A numeric response alone is not a complete geometric proof; the written review supplies the missing reasons and the teacher-review flag remains until the reasoning has been checked in class.

## Authored question bank

Each whiteboard example shows the problem, marked parallel lines and a visible first angle. The intermediate angle is concealed until its relationship is explained. The second angle and final answer appear only after their own mathematical steps. Previous results persist in the written solution.

### Worked example 1: g8-lines-05-w01
Two parallel lines are cut by a transversal. The upper marked angle is 45°. A learner writes: “The corresponding angles add to 180°.” Find the first unsupported claim, repair it, then find the lower angle x.

Diagram: corresponding_linear; given 45°, first intermediate sector 45°, target sector 135°; initial target label x.
Whiteboard sequence:

1. Locate the two marked parallel lines and transversal; read the given 45° angle.
2. Read the learner claim exactly: “The corresponding angles add to 180°.”
3. The first unsupported claim is “The corresponding angles add to 180°.”: the marked pair is corresponding.
4. Corresponding angles are equal, so the lower marked angle is 45°.
5. Adjacent angles on a straight line add to 180°, so the target angle is 180° − 45° = 135°.
6. Therefore x = 135°.

Answer: corresponding; 135°. Check: The transferred angle is 45°; 45° + 135° = 180°.
Misconception: Use the named angle theorem, then the second relationship; do not measure the picture.
