# Grade 8 Graphs Lesson 2 — Tables to graphs and graphs to tables

**Status:** Athena-authored source; teacher review required. These are original questions, not copied exercises.

CAPS scope: plot points from tables or ordered pairs and draw graphs on the Cartesian plane. [2026 DBE Grade 8 ATP](https://www.education.gov.za/Portals/0/Documents/Publications/2026/Circulars/Circular%20S19%20of%202025%20and%20Annexures.pdf). [Siyavula topic outline](https://www.siyavula.com/read/za/mathematics/grade-8/graphs/23-graphs-06).

The question's table is the source of truth. The board plots one matched column at a time, keeps earlier points visible, and draws a line only where the input domain and data justify one. A given graph is visible initially without revealing its coordinate answers. A learner error remains visible beside its correction.

## Worked examples

### 01 — foundation

**Question (2 marks):** Plot the table x: 0, 1, 2 and y: 1, 2, 3. Draw the straight-line graph.

**Whiteboard:** Axis x [-2, 4] by 1; y [-2, 5] by 1. Mode: line. Initial dots: none. Plot stages: A (0, 1) at step 1; B (1, 2) at step 2; C (2, 3) at step 3. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** Match x = 0 with y = 1; plot (0, 1). → Match x = 1 with y = 2; plot (1, 2). → Match x = 2 with y = 3; plot (2, 3). → The three points align; draw the straight line through them.

**Full memo:** The pairs are (0, 1), (1, 2), (2, 3). They satisfy y = x + 1, so the graph is the straight line through all three.

**Misconception:** Putting all x values on one axis without matching their y row. **Repair:** Point to one table column and read its x and y together.

### 02 — easy

**Question (2 marks):** For y = 2x + 2, complete the table at x = −1, 0, 1 and plot the graph.

**Whiteboard:** Axis x [-3, 3] by 1; y [-2, 6] by 1. Mode: line. Initial dots: none. Plot stages: A (-1, 0) at step 1; B (0, 2) at step 2; C (1, 4) at step 3. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** Substitute −1: 2(−1) + 2 = 0; plot (−1, 0). → Substitute 0: 2(0) + 2 = 2; plot (0, 2). → Substitute 1: 2(1) + 2 = 4; plot (1, 4). → Each step right adds two vertically; draw one straight line.

**Full memo:** The outputs are 0, 2 and 4, giving (−1, 0), (0, 2), (1, 4); all satisfy y = 2x + 2.

**Misconception:** Dropping the negative sign when substituting −1. **Repair:** Evaluate 2(−1) before adding 2 and check the x-axis crossing.

### 03 — easy

**Question (3 marks):** The table has x: 0, 2, 4 and y: 3, 3, 3. Plot it and describe the graph.

**Whiteboard:** Axis x [-2, 6] by 1; y [-2, 5] by 1. Mode: line. Initial dots: none. Plot stages: A (0, 3) at step 1; B (2, 3) at step 2; C (4, 3) at step 3. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** Read the first column: (0, 3). → Read the second column: (2, 3). → Read the third column: (4, 3). → Join the three points horizontally at y = 3.

**Full memo:** Every output is 3. The graph is the horizontal line y = 3 through (0, 3), (2, 3), (4, 3).

**Misconception:** Drawing a vertical line because the output stays fixed. **Repair:** Keep the y-guide at 3 while x moves; the line is horizontal.

### 04 — standard

**Question (3 marks):** For y = 5 − x, plot the entries x: 0, 2, 4 and describe the direction.

**Whiteboard:** Axis x [-2, 6] by 1; y [-2, 7] by 1. Mode: line. Initial dots: none. Plot stages: A (0, 5) at step 1; B (2, 3) at step 2; C (4, 1) at step 3. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** At x = 0, y = 5; plot (0, 5). → At x = 2, y = 3; plot (2, 3). → At x = 4, y = 1; plot (4, 1). → Draw the falling straight line and read the change.

**Full memo:** The graph falls two y-units for every two x-units: pairs (0, 5), (2, 3), (4, 1) all satisfy y = 5 − x.

**Misconception:** Adding x to 5 instead of subtracting. **Repair:** Check y at x = 4 by calculating 5 − 4 explicitly.

### 05 — standard

**Question (3 marks):** Plot y = 2x for x = −2, 0, 2. State where it crosses the axes.

**Whiteboard:** Axis x [-4, 4] by 1; y [-6, 6] by 1. Mode: line. Initial dots: none. Plot stages: A (-2, -4) at step 1; B (0, 0) at step 2; C (2, 4) at step 3. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** Multiply −2 by 2: plot (−2, −4). → Multiply 0 by 2: plot the origin (0, 0). → Multiply 2 by 2: plot (2, 4). → Join the points through (0, 0) and check the crossing.

**Full memo:** The straight graph passes through the origin, which is its crossing with both axes; the pairs satisfy y = 2x.

**Misconception:** Treating 2(−2) as positive four. **Repair:** Use signed multiplication before plotting the left point.

### 06 — standard

**Question (4 marks):** Plot y = 2 − x for x = −1, 1, 3. Explain the downward trend.

**Whiteboard:** Axis x [-3, 5] by 1; y [-3, 5] by 1. Mode: line. Initial dots: none. Plot stages: A (-1, 3) at step 1; B (1, 1) at step 2; C (3, -1) at step 3. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** At −1, calculate 2 − (−1) = 3. → At 1, calculate 2 − 1 = 1. → At 3, calculate 2 − 3 = −1. → Plot all three and draw the descending straight line.

**Full memo:** The pairs are (−1, 3), (1, 1), (3, −1); each rise of two in x reduces y by two.

**Misconception:** Misreading 2 − (−1) as 1. **Repair:** Write subtraction of a negative as addition, then check each plotted pair.

### 07 — intermediate

**Question (4 marks):** Complete y = 3x + 1 for x = 0, 1, 2, then plot and join the points.

**Whiteboard:** Axis x [-2, 4] by 1; y [-2, 9] by 1. Mode: line. Initial dots: none. Plot stages: A (0, 1) at step 1; B (1, 4) at step 2; C (2, 7) at step 3. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** Replace x by 0: y = 1; plot (0, 1). → Replace x by 1: y = 4; plot (1, 4). → Replace x by 2: y = 7; plot (2, 7). → Draw the line; each x increase of one adds three to y.

**Full memo:** Outputs 1, 4, 7 form (0, 1), (1, 4), (2, 7), all on y = 3x + 1.

**Misconception:** Using 3(x + 1) rather than 3x + 1. **Repair:** Multiply x first; add one only afterwards.

### 08 — intermediate

**Question (4 marks):** A table shows x: 0, 1, 2 and y: 4, 3, 2. Plot the pairs, not their reversed forms.

**Whiteboard:** Axis x [-2, 4] by 1; y [-2, 6] by 1. Mode: line. Initial dots: none. Plot stages: A (0, 4) at step 1; B (1, 3) at step 2; C (2, 2) at step 3. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** The first column is (0, 4), on the y-axis. → The second column is (1, 3), not (3, 1). → The third column is (2, 2). → Join the falling points and read back all columns.

**Full memo:** The graph uses (0, 4), (1, 3), (2, 2), satisfying y = 4 − x.

**Misconception:** Reversing the input-output ordered pairs. **Repair:** Place each column as (input, output) and project to both axes.

### 09 — intermediate

**Question (5 marks):** x ticks count by 2 and y ticks by 5. Plot table pairs (0, 0), (2, 5), (4, 10).

**Whiteboard:** Axis x [-4, 8] by 2; y [-10, 20] by 5. Mode: line. Initial dots: none. Plot stages: A (0, 0) at step 1; B (2, 5) at step 2; C (4, 10) at step 3. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** Read the x and y labels separately; plot (0, 0). → One x interval is two and one y interval is five, giving (2, 5). → Two x intervals give four and two y intervals give ten, giving (4, 10). → Join the aligned points; verify their numeric labels.

**Full memo:** The plotted pairs (0, 0), (2, 5), (4, 10) form a straight line; one grid square represents different values on the two axes.

**Misconception:** Using one unit per square on both axes. **Repair:** Read the marked ticks before counting squares on either axis.

### 10 — exam

**Question (5 marks):** The graph shows P at (0, 1), Q at (1, 3), R at (2, 5). Build the corresponding x/y table.

**Whiteboard:** Axis x [-2, 4] by 1; y [-2, 7] by 1. Mode: given_line. Initial dots: A, B, C. Plot stages: . All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** Project P: x = 0, y = 1; write the first table column. → Project Q: x = 1, y = 3; write the next column. → Project R: x = 2, y = 5; write the final column. → Read the columns in increasing x order and check y = 2x + 1.

**Full memo:** The table has x: 0, 1, 2 and y: 1, 3, 5. The visible points satisfy y = 2x + 1.

**Misconception:** Reading graph points in label order without pairing x and y. **Repair:** Project each dot to its two labelled axes before entering a column.

### 11 — exam

**Question (5 marks):** A learner plots y = 2x + 1 at (0, 1), (1, 3), (2, 4). Find and repair the wrong point.

**Whiteboard:** Axis x [-2, 4] by 1; y [-2, 7] by 1. Mode: error. Initial dots: Learner C. Plot stages: A (0, 1) at step 1; B (1, 3) at step 2; C (2, 5) at step 4. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** Check x = 0: 2(0) + 1 = 1, so the first dot is right. → Check x = 1: 2(1) + 1 = 3, so the second dot is right. → At x = 2, 2(2) + 1 = 5, not 4. → Keep the incorrect dot visible and correct it to (2, 5).

**Full memo:** The first wrong point is (2, 4); replace it with (2, 5). The three correct points lie on y = 2x + 1.

**Misconception:** Stopping at multiplication and forgetting the final +1. **Repair:** Calculate 2(2) + 1 in two separate operations, then compare with the learner dot.

### 12 — exam

**Question (6 marks):** Each whole ticket costs R5 plus one R10 booking fee. Plot total cost for 0, 1, 2 tickets. Should the dots be joined?

**Whiteboard:** Axis x [-2, 4] by 1; y [-10, 30] by 5. Mode: discrete. Initial dots: none. Plot stages: A (0, 10) at step 1; B (1, 15) at step 2; C (2, 20) at step 3. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** Zero tickets still incurs the R10 booking fee: (0, 10). → One ticket costs 10 + 5 = 15: plot (1, 15). → Two tickets cost 10 + 10 = 20: plot (2, 20). → Keep separate dots: half a whole ticket is not an allowed input.

**Full memo:** At x = 0, 1, 2 the totals are R10, R15, R20. Whole tickets give discrete points; do not imply fractional tickets by joining them.

**Misconception:** Joining discrete points and suggesting half a ticket. **Repair:** Ask whether x = 1.5 tickets is permitted before drawing any connecting line.

### 13 — advanced

**Question (6 marks):** A temperature graph uses time 0, 2, 4 hours and values 2, 5, 8 °C. Plot and draw the measured straight trend.

**Whiteboard:** Axis x [-4, 8] by 2; y [-2, 10] by 1. Mode: line. Initial dots: none. Plot stages: A (0, 2) at step 1; B (2, 5) at step 2; C (4, 8) at step 3. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** Label time on x and temperature on y; plot (0, 2). → At 2 hours the temperature is 5 °C; plot (2, 5). → At 4 hours the temperature is 8 °C; plot (4, 8). → Draw the straight trend through the measured points.

**Full memo:** The measured pairs are (0, 2), (2, 5), (4, 8), with a rise of 3 °C every 2 hours across the sampled interval.

**Misconception:** Swapping the time and temperature axes. **Repair:** Read units beside both axes and interpret (2, 5) aloud.

### 14 — advanced

**Question (6 marks):** The rule y = 3x + 1 gives (0, 1), (1, 4), (2, 7). Predict and plot the next point at x = 3.

**Whiteboard:** Axis x [-2, 5] by 1; y [-2, 12] by 1. Mode: line. Initial dots: none. Plot stages: A (0, 1) at step 1; B (1, 4) at step 2; C (2, 7) at step 3; D (3, 10) at step 4. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** Plot the known pair (0, 1). → Plot (1, 4) and (2, 7), retaining the first dot. → Extend the table: y = 3(3) + 1 = 10. → Plot (3, 10), draw the line and verify it follows the rule.

**Full memo:** At x = 3 the next output is 10, so (3, 10) extends the same straight line y = 3x + 1.

**Misconception:** Extending the x pattern but leaving y at 7. **Repair:** Use the rule, not just the diagram, to calculate the new output.

### 15 — advanced

**Question (7 marks):** Table x: 0, 1, 2, 3; y: 0, 1, 4, 9. Plot all pairs. Is one straight line through them justified?

**Whiteboard:** Axis x [-2, 5] by 1; y [-2, 11] by 1. Mode: nonlinear. Initial dots: none. Plot stages: A (0, 0) at step 1; B (1, 1) at step 2; C (2, 4) at step 3; D (3, 9) at step 3. All earlier dots remain. The line appears on step 4 only for a continuous straight relationship.

**Teaching sequence:** Plot (0, 0) from the first column. → Plot (1, 1) and (2, 4) from their own columns. → Plot (3, 9); keep the previous dots visible. → Compare rises 1, 3, 5: they differ, so reject one straight line.

**Full memo:** The pairs (0, 0), (1, 1), (2, 4), (3, 9) have unequal rises 1, 3, 5 for equal x-steps. Do not draw a single straight line through them.

**Misconception:** Forcing any table into a straight-line graph. **Repair:** Compare successive y-differences for equal x-steps before choosing a straight line.
