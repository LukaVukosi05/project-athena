## g8-graphs-l04-w01: A tap fills a tank

**Question.** A tap fills a tank: The empty tank gains 2 litres each minute. Sketch the graph with minutes horizontally and litres vertically. Explain the change on each interval and whether the plotted marks should be joined.
**Domain.** continuous; horizontal: minutes; vertical: litres.
**Source coordinates.** (0, 0), (1, 2), (2, 4), (3, 6).

**Board sequence**
1. Label the horizontal axis minutes and vertical axis litres. Start at (0, 0), because the story begins with 0 litres.
2. Plot (1, 2) and show the first interval 0 to 1: litres increases by 2.
3. Keep that interval visible; plot (2, 4). From 1 to 2, litres increases by 2.
4. Plot (3, 6). On the last interval litres increases by 2. The final point is (3, 6); connect only across meaningful inputs. Check each point against the story.

**Full memo.** The empty tank gains 2 litres each minute. The graph values are (0, 0), (1, 2), (2, 4), (3, 6). The final point is (3, 6); connect only across meaningful inputs. Therefore (0, 0) → (1, 2) → (2, 4) → (3, 6); connected graph.
**Likely error.** Confusing minutes with litres or treating a flat interval as a missing point.
**Repair.** Project each endpoint to the minutes and litres axes; compare consecutive outputs and check whether intermediate inputs are meaningful.
