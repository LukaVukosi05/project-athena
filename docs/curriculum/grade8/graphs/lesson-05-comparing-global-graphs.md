## g8-graphs-l05-w01: Two water tanks

**Question.** Two water tanks: graph A and graph B show litres against minutes. Which tank gains more water from minute 0 to minute 3?
**Axis data.** {'x_min': 0, 'x_max': 4, 'y_min': -2, 'y_max': 8, 'x_tick': 1, 'y_tick': 1, 'x_unit': 'minutes', 'y_unit': 'litres'}
**Graph points.** [{'x': 0, 'y': 0}, {'x': 1, 'y': 2}, {'x': 2, 'y': 4}, {'x': 3, 'y': 6}] and B: [{'x': 0, 'y': 0}, {'x': 1, 'y': 1}, {'x': 2, 'y': 3}, {'x': 3, 'y': 5}]

**Whiteboard actions**
1. Check both labelled axes. At minutes 0, graph A starts at 0 litres and graph B at 0 litres.
2. Trace graph A from input 0 to 3. Its value rises from 0 to 6, a change of +6.
3. Trace graph B on the same scale. For the overall change, calculate A = 6 and B = 5 litres. Compare the two at the same input or interval.
4. For the asked comparison, the answer is A. Recheck A: [0, 2, 4, 6], B: [0, 1, 3, 5], with the same minutes scale.

**Memo.** Which tank gains more water from minute 0 to minute 3? A has [0, 2, 4, 6]; B has [0, 1, 3, 5]. The comparison at the requested input or interval gives A.
**Misconception.** Comparing values at different inputs or comparing total rise when the question asks about one interval.
**Targeted repair.** Align the same horizontal inputs and project each graph to the vertical axis before comparing.
