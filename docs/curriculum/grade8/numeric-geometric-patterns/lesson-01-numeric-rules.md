## g8-patterns-l01-w01 — Step of three
**Question:** Step of three: the first terms are 4, 7, 10, 13. Find the next term and justify the rule with the diagram.
**Model:** add. **Given:** [4, 7, 10, 13].
**Whiteboard:** Read the given values 4, 7, 10, 13 in order; do not treat the next term as given. → Mark each successive difference 3, 3, 3. → Choose a rule that works at every given position; 4 + 3 = 7, 7 + 3 = 10, 10 + 3 = 13, so the next term is 16. → Check against the original four values; the next value is 16.
**Answer and verification:** 16. 4 + 3 = 7, 7 + 3 = 10, 10 + 3 = 13, so the next term is 16.
**Misconception repair:** Check the proposed rule against every given figure or term before extending it.
