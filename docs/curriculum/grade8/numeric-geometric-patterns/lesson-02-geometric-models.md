## g8-patterns-l02-w01 — Matchstick squares
**Question:** Matchstick squares: Figures 1–4 contain 4, 7, 10, 13 matchsticks. Find the number in Figure 5 and justify the model.
**Model:** joined_squares. **Given:** [4, 7, 10, 13].
**Whiteboard:** Read the given values 4, 7, 10, 13 in order; do not treat the next term as given. → Mark each successive difference 3, 3, 3. → Build the next figure one group at a time; A row of joined squares uses 4 then 3 new sticks for each additional square. → Check against the original four values; the next value is 16.
**Answer and verification:** 16. A row of joined squares uses 4 then 3 new sticks for each additional square.
**Misconception repair:** Check the proposed rule against every given figure or term before extending it.
