## g8-patterns-l03-w01: Three more each time
**Question:** Three more each time: the outputs at positions 1, 2, 3, 4 are 5, 7, 9, 11. Write one algebraic rule T(n) for the value at position n. Verify it at position 4.
**Position row:** 1, 2, 3, 4. **Given output row:** [5, 7, 9, 11].
**Rule structure:** linear; a=2, b=3. **Target:** 6.
1. Align positions 1, 2, 3, 4 above outputs 5, 7, 9, 11.
2. Calculate adjacent differences. Every change is 2; this is the coefficient of n.
3. Use position one: 5 = 2 × 1 + b, so the fixed part b is 3.
4. Write T(n) = 2n + 3. Substitute n=4 and check that the result is 11.
**Answer:** 2n + 3. **Full check:** T(n) = 2n + 3. At n=1, T(1)=5; at n=4, T(4)=11. Count the first term as 5; two new pieces are added for every new position.
**Misconception:** A rule matched only one adjacent pair rather than all known positions.
**Reteach:** Align n and T(n), rebuild the operation, check the first and fourth givens, and retry with new values.
