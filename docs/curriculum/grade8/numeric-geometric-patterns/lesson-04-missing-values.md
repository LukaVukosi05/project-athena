## g8-patterns-l04-w01: Square plus two
**Question:** Square plus two: T(n) = 1n² + 2. The table shows positions 1–4 as 3, 6, 11, 18. Find the missing value at position 5.
**Position row:** 1, 2, 3, 4. **Given output row:** [3, 6, 11, 18].
**Rule structure:** square_offset; a=1, b=2. **Target:** 5.
1. Write the known position row 1, 2, 3, 4 and the target position 5; the missing output stays hidden.
2. Choose the given rule T(n) = 1n² + 2; check it reproduces position 1 (3) and position 4 (18).
3. Substitute n=5 into the same rule. Square the position, then add two.
4. Calculate the missing output 27. Check its position and rule against the original table.
**Answer:** 27. **Full check:** T(5) = 27. Square the position, then add two. Check with T(1)=3 and T(4)=18.
**Misconception:** The wrong position or order of operations was used in the rule.
**Reteach:** Align n and T(n), rebuild the operation, check the first and fourth givens, and retry with new values.
