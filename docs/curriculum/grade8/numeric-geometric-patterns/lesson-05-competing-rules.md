## g8-patterns-l05-w01: Growing tiles
**Question:** Growing tiles: positions 1–4 have outputs 5, 8, 11, 14. Rule A is 3n + 2; Rule B is 4n + 1. Which rule fits all positions, and what does it predict at position 5?
**Given outputs:** [5, 8, 11, 14]. **Target position:** 5.
1. Align positions 1–4 with their outputs 5, 8, 11, 14; both proposed rules agree at position one.
2. Calculate the outputs predicted by Rule A (3n + 2) and Rule B (4n + 1) at position 2.
3. At position 2, Rule B predicts 9, but the given output is 8; reject that rule.
4. Rule A fits all four outputs. Use it at position 5: T(5) = 17; check again at positions 1 and 4.
**Answer:** Rule A: 3n + 2. At n=2, reject Rule B (9 ≠ 8). T(5)=17; check T(1)=5 and T(4)=14.
**Misconception:** Rule B agrees at position one but fails at position 2.
**Reteach:** Calculate both candidates at two distant given positions, reject a counterexample, and retry with a different pair.
