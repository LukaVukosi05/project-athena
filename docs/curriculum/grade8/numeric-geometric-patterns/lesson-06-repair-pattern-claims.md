## g8-patterns-l06-w01: Five added daily
**Question:** Five added daily: the first four outputs are 7, 12, 17, 22. A learner predicts 27 at position 6. Find the first error and repair the prediction.
**Given outputs:** [7, 12, 17, 22]. **Target position:** 6.
1. Align the first four outputs 7, 12, 17, 22 with positions 1–4. The learner claims T(6) = 27.
2. Compare the changes 5, 5, 5. The claim assumes the previous position.
3. Rebuild the pattern rule T(n) = 5n + 2. Test it at positions 1 and 4, where it returns 7 and 22.
4. Now substitute n=6: T(6) = 32, not 27. Check the repaired value against the rule and the direction of change.
**Answer:** The claim 27 misuses the position index. T(n)=5n + 2 gives T(6)=32. It returns 7 and 22 at positions 1 and 4.
**Misconception:** The learner used off by one instead of testing the pattern at the requested position.
**Reteach:** Identify the first invalid claim, reconstruct the table and rule, then independently reassess at a different position.

## Misconception repair and mastery decision

If the learner cannot reject the incorrect claim or rule, return to the first mismatched position. Rebuild the two candidate rows or the original pattern, then check positions one and four before attempting a new target. A mastery score below 80% routes to this repair and a parallel reassessment.
