# Grade 9 Topic 7 · Lesson 5: Factorisation and the zero-product property

Authority: [DBE 2026 Mathematics Grade 9 ATP](https://www.education.gov.za/Portals/0/Documents/Recovery%20plan%20page/2026%20ATPs/2026_ATP_Mathematics_Grade%209.pdf), Term 2. Questions and scenarios are original Athena content.

Status: teacher and browser review required. Worked examples show each intermediate equality and a substitution check. Practice is independent and four-option.

## g9-eq-l05-w01: Solve (x − 2)(x + 3) = 0. Give every solution and check the zero-product rule.

1. The product is zero, so at least one factor must equal zero.

2. First factor: x − 2 = 0, therefore x = 2.

3. Second factor: x + 3 = 0, therefore x = -3.

4. Check: (2 − 2)(2 + 3) = 0 and (-3 − 2)(-3 + 3) = 0.

**Answer:** x = 2 or x = -3. **Misconception:** Set each factor equal to zero; do not divide by a possibly zero factor or omit a root.
