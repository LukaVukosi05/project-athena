## g9-eq-l06-w01: The rule is y = 3x + 4. Complete the outputs for x = 2 and x = 4, then find x when y = 13.

1. Keep the ordered-pair columns aligned: inputs 2, 4 and the unknown input.

2. For x = 2, y = 3(2) + 4 = 10; write (2, 10).

3. For x = 4, y = 3(4) + 4 = 16; write (4, 16).

4. For y = 13, solve 3x + 4 = 13: x = 3.

5. Check: 3(3) + 4 = 13; the ordered pair is (3, 13).

**Answer:** x = 3. **Misconception:** The ordered pair is (input, output); inverse lookup must undo the addition before division.
