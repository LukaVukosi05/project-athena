## Worked examples

### g9-exp-l06-w01 · foundation
Question: A learner says 2² × 2³ = 64 because the exponents multiply. Find the first error and corrected result.
Givens: 2; 2; 3
Visual: {"family": "diagnosis", "kind": "product", "base": "2", "exponents": [2, 3], "claim": "64", "correction": "32"}
1. The bases match: 2.
2. The first error is multiplying exponents 2×3; a product of powers adds them.
3. Use 2+3=5; 2⁵ = 32.
4. Check: The corrected expression evaluates to 32, not 64.
Answer: 32
Misconception: first-error-product

### g9-exp-l06-p01
Question: A learner says 2⁴ × 2² = 256 because the exponents multiply. Find the first error and corrected result.
A. 64
B. 256
C. 20
D. 32
Key: A
Memo: 64. The bases match: 2. The first error is multiplying exponents 4×2; a product of powers adds them. Use 4+2=6; 2⁶ = 64. Check: The corrected expression evaluates to 64, not 256.
Distractor 256: Incorrect: Keeps the learner’s exponent product.
Distractor 20: Incorrect: Adds power values instead of exponents.
Distractor 32: Incorrect: Omits the final repeated factor.
