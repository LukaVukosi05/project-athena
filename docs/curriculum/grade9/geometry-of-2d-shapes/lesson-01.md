## g9-shapes-l01-w01: Equilateral triangle ABC has AB = BC = CA = 4 cm. Find angle B and give a reason.

Visual: {"family": "shapes", "values": {"kind": "triangle", "lesson": 1, "model": "equilateral", "side": 4, "target": 60}}

1. Mark all three equal sides, each 4 cm.

2. All three angles opposite these sides are equal: ∠A = ∠B = ∠C = x.

3. Triangle angle sum: x + x + x = 180°.

4. Divide 180° by 3: x = 60°.

5. Check: 60° + 60° + 60° = 180°.

**Answer:** ∠B = 60°. **Misconception:** A diagram alone does not prove a property; mark the given equality and state the applicable reason.

## g9-shapes-l01-w02: Right triangle ABC has ∠B = 90°, ∠A = 26° and BC = 5 cm. Find ∠C.

Visual: {"family": "shapes", "values": {"kind": "triangle", "lesson": 1, "model": "right", "given": 26, "side": 5, "target": 64}}

1. Mark the right angle at B and ∠A = 26°.

2. The three interior angles of a triangle total 180°.

3. Write 26° + 90° + ∠C = 180°.

4. Calculate ∠C = 180° − 90° − 26° = 64°.

5. Check: 26° + 90° + 64° = 180°.

**Answer:** ∠C = 64°. **Misconception:** A diagram alone does not prove a property; mark the given equality and state the applicable reason.

## g9-shapes-l01-w03: Isosceles triangle ABC has AB = AC and apex angle A = 36°. Find base angle B, with a reason.

Visual: {"family": "shapes", "values": {"kind": "triangle", "lesson": 1, "model": "isosceles", "apex": 36, "target": 72}}

1. Mark equal sides AB and AC, and read ∠A = 36°.

2. Equal sides face equal base angles, so ∠B = ∠C = x.

3. Use the triangle angle sum: 36° + x + x = 180°.

4. Subtract 36°: 2x = 144°; divide by 2: x = 72°.

5. Check: 36° + 72° + 72° = 180°.

**Answer:** ∠B = 72°. **Misconception:** A diagram alone does not prove a property; mark the given equality and state the applicable reason.
