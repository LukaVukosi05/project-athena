## g9-shapes-l03-w02: ABCD is a rhombus. ∠A = 46°. Find adjacent ∠B, naming the property.

Visual: {"family": "shapes", "values": {"kind": "quadrilateral", "lesson": 3, "model": "rhombus", "given": 46, "target": 134}}

1. Locate ∠A = 46° and adjacent ∠B.

2. Use the property: a rhombus is a parallelogram, so adjacent angles are supplementary.

3. Write 46° + ∠B = 180°.

4. Calculate ∠B = 180° − 46° = 134°.

5. Check: 46° + 134° = 180°.

**Answer:** ∠B = 134°. **Misconception:** A diagram alone does not prove a property; mark the given equality and state the applicable reason.

## g9-shapes-l03-w03: Trapezium ABCD has AB ∥ CD. ∠A = 49°. Find ∠D on the same transversal AD.

Visual: {"family": "shapes", "values": {"kind": "quadrilateral", "lesson": 3, "model": "trapezium", "given": 49, "target": 131}}

1. Mark the one parallel pair AB ∥ CD and the transversal AD; ∠A = 49°.

2. ∠A and ∠D are co-interior angles.

3. Co-interior angles sum to 180°: 49° + ∠D = 180°.

4. Calculate ∠D = 131°.

5. Check: 49° + 131° = 180°.

**Answer:** ∠D = 131°. **Misconception:** A diagram alone does not prove a property; mark the given equality and state the applicable reason.
