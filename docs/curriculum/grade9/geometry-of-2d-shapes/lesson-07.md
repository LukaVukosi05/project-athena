## g9-shapes-l07-w01: AB = AC in triangle ABC. ∠A = 32° and ∠B = x. Find x, giving each geometric reason.

Visual: {"family": "shapes", "values": {"kind": "triangle", "lesson": 7, "model": "isosceles", "apex": 32, "target": 74}}

1. Observe AB = AC and the given apex angle ∠A = 32°.

2. Equal sides imply ∠B = ∠C = x, since base angles of an isosceles triangle are equal.

3. Triangle angle sum gives 32° + x + x = 180°.

4. 2x = 148°, hence x = 74°.

5. Check: 32° + 2(74°) = 180°.

**Answer:** x = 74°. **Misconception:** A diagram alone does not prove a property; mark the given equality and state the applicable reason.
