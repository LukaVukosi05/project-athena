## g9-shapes-l08-w01: In isosceles △ABC, AB = AC and ∠A = 32°. A learner writes ∠B = 180° − 32° = 148°. Identify the first error and find ∠B.

Visual: {"family": "shapes", "values": {"kind": "pair", "lesson": 8, "model": "diagnosis", "apex": 32, "target": 74, "claimed": 148}}

1. Keep AB = AC and the apex angle 32° visible.

2. The learner assigned all 148° remaining to one base angle.

3. This is the first error: equal sides require two equal base angles, not one.

4. Split the remaining angle equally: ∠B = ∠C = (148°) ÷ 2 = 74°.

5. Check: 32° + 74° + 74° = 180°.

**Answer:** ∠B = 74°. **Misconception:** A diagram alone does not prove a property; mark the given equality and state the applicable reason.
