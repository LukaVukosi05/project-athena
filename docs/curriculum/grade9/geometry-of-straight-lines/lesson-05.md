## g9-lines-l05-w01: At two marked parallel lines, a alternate pair includes the given 47° angle and target x. A learner writes x = 133°. Locate the first incorrect reason and repair it.

Visual: {"family": "straight_lines", "values": {"kind": "parallel", "theta": 47, "lesson": 5, "relation": "alternate", "given": 47, "target": 47, "claimed": 133}}

1. Find the given 47° sector and the separate target x, using the parallel marks.

2. The learner wrote x = 133°; identify which sectors were compared.

3. Check the diagram: the pair is alternate, so alternate angles are equal: x = 47°.

4. The learner used the wrong relationship at the previous step. Repair x = 47°.

5. Check: both marked alternate sectors equal 47°.

**Answer:** x = 47°. **Misconception:** Name the exact angle pair and its parallel or perpendicular markings; visual appearance alone is not proof.
