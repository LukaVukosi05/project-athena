## g9-gr-l02-w01: Complete the table for y = 3x + 3 at x = −1, 0, 1 and 2. Plot each ordered pair. What is the point at x = 2?

Visual: {"family": "ordered", "values": {"m": 3, "b": 3, "points": [[-1, 0], [0, 3], [1, 6], [2, 9]]}}

1. For x = −1, y = 3(−1) + 3 = 0; plot (−1, 0).

2. For x = 0, y = 3; plot (0, 3) on the vertical axis.

3. For x = 1, y = 6; plot (1, 6).

4. For x = 2, y = 9; plot (2, 9).

5. Check: substituting 2 in y = 3x + 3 gives y = 9.

**Answer:** (2, 9). **Misconception:** Keep axes and ordered-pair positions fixed; reveal each calculated point before joining a line.
