## g9-gr-l03-w01: Find the gradient of the straight line through A(-1, 0) and B(2, 9). Draw and label a rise/run triangle.

Visual: {"family": "gradient", "values": {"m": 3, "b": 3, "points": [[-1, 0], [2, 9]], "run": 3, "rise": 9}}

1. Plot A(-1, 0) and B(2, 9) on the same axes.

2. From A to B the horizontal run is 2 − (-1) = 3.

3. The vertical rise is 9 − (0) = 9.

4. Gradient = rise ÷ run = 9 ÷ 3 = 3.

5. Check: moving 3 units right changes y by 9, so the gradient is 3.

**Answer:** gradient = 3. **Misconception:** Keep axes and ordered-pair positions fixed; reveal each calculated point before joining a line.
