## g9-gr-l04-w01: Find and plot both axis intercepts of y = 3x + 9. State them as ordered pairs.

Visual: {"family": "intercepts", "values": {"m": 3, "b": 9, "x_intercept": -3, "points": [[-3, 0], [0, 9]]}}

1. At the y-axis x = 0, so y = 3(0) + 9 = 9.

2. Plot the y-intercept (0, 9).

3. At the x-axis y = 0: 0 = 3x + 9.

4. Solve for x: 3x = -9, so x = -3; plot (-3, 0).

5. Check: 3(-3) + (9) = 0, and x=0 gives y=9.

**Answer:** (-3, 0) and (0, 9). **Misconception:** Keep axes and ordered-pair positions fixed; reveal each calculated point before joining a line.
