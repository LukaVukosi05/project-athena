## g9-gr-l06-w01: A straight line passes through (0, 3), (1, 6) and (2, 9). Find its equation in the form y = mx + c.

Visual: {"family": "infer", "values": {"m": 3, "b": 3, "points": [[0, 3], [1, 6], [2, 9]]}}

1. Plot the first given point (0, 3).

2. Plot the next given point (1, 6).

3. Plot (2, 9); the three points align.

4. The y-intercept is (0, 3), so c = 3.

5. From (0, 3) to (1, 6), rise = 3 and run = 1.

6. The gradient is m = 3 ÷ 1 = 3; the rule is y = 3x + 3.

7. Check: at x=2 the rule gives 3(2)+(3) = 9, matching (2, 9).

**Answer:** y = 3x + 3. **Misconception:** Keep axes and ordered-pair positions fixed; reveal each calculated point before joining a line.
