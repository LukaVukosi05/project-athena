## g9-gr-l07-w01: A line passes through (0, 3), (1, 6), (2, 9). A learner claims its gradient is 4, so its equation is y = 4x + 3. Identify the first error and give the correct equation.

1. Plot the original point (0, 3).

2. Plot the original point (1, 6).

3. Plot the original point (2, 9); retain both earlier points.

4. Test the learner claim at x=1: 4(1)+(3) = 7, but the given y is 6.

5. The first error is the gradient: the actual rise from x=0 to x=1 is 6 − (3) = 3.

6. The run is 1, so the correct gradient is 3; the y-intercept remains 3.

7. Repair the equation to y = 3x + 3.

8. Check: at x=2, 3(2)+(3) = 9, the given output.

**Answer:** y = 3x + 3. **Misconception:** Keep axes and ordered-pair positions fixed; reveal each calculated point before joining a line.
