Question: Arrange -8, 3 and -2 in ascending order.
Givens: -8; 3; -2
Visual: {"family": "line", "values": [-8, 3, -2], "path": [-8, -2, 3], "labels": ["first", "second", "third"]}
1. Mark zero as the reference on the signed number line.
2. Place each value at its exact tick: -8, 3, -2.
3. Read the ticks from left to right: -8, -2, 3.
4. Check: -8 < -2 < 3.
Answer: -8, -2, 3
