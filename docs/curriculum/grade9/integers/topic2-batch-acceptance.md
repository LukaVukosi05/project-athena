## Release gates

- Mathematics teacher checks all 75 worked examples and 115 independent items, especially sign conventions, context wording, principal square roots and distractor explanations.
- Open all five lessons in the real browser on desktop and a narrow phone. Inspect at least four examples in each, including initial, operation, result, final check, Previous/Next/replay and direct URL restoration. Run `node tools/verify_grade9_integers_browser.mjs` with a locally installed Chromium/Chrome if necessary.
- Test a wrong answer through first-error feedback and changed-value reassessment, not merely the API key.
- Reconsider difficulty progression after teacher review: the last examples are mixed or diagnostic, but their actual challenge level needs classroom judgement.
