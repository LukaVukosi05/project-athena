## g9-prob-l01-w01: A fair spinner has equally sized sectors numbered 1 to 7. List the sample space size and find P(a multiple of 3).

Visual: {"family": "probability", "values": {"lesson": 1, "model": "sample_grid", "outcomes": [1, 2, 3, 4, 5, 6, 7], "favourable": 2}}

1. List all sectors 1, 2, …, 7; there are 7 equally likely outcomes.

2. Mark multiples of 3: 3, 6.

3. Favourable outcomes = 2; possible outcomes = 7.

4. Probability = 2/7.

5. Check: 0 ≤ 2/7 ≤ 1; only multiples of 3 are highlighted.

**Answer:** sample space size = 7; P(multiple of 3) = 2/7. **Misconception:** Choose the correct sample space and denominator, then distinguish a path product from addition and observation from prediction.
