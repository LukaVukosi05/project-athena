## g9-tg-l01-w01: Triangle A(-1, -1), B(2, -1), C(-1, 1) is transformed by translation by (3, -2). Plot the image and give its vertex coordinates.

Visual: {"family": "transformation", "values": {"lesson": 1, "kind": "translate", "original": [[-1, -1], [2, -1], [-1, 1]], "image": [[2, -3], [5, -3], [2, -1]], "dx": 3, "dy": -2, "centre": [0, 0], "factor": 1, "rule": "translation by (3, -2)", "model": "coordinate_transform", "original_area": null}}

1. Plot and label the original vertices A(-1, -1), B(2, -1), C(-1, 1) on one fixed set of axes.

2. Mark the translation by (3, -2); Add 3 to x and -2 to y at every vertex.

3. Map A (-1, -1) to A′(2, -3); retain A and A′.

4. Map B (2, -1) to B′(5, -3) and C (-1, 1) to C′(2, -1); join A′B′C′.

5. Check the coordinate rule on all three vertices; image A′(2, -3), B′(5, -3), C′(2, -1).

**Answer:** A′(2, -3), B′(5, -3), C′(2, -1). **Misconception:** Apply the same rule to both coordinates of every vertex; check the centre, axis and scale.
