## g9-tg-l03-w01: Triangle A(-1, -1), B(2, -1), C(-1, 1) is transformed by reflection in y = x. Plot the image and give its vertex coordinates.

Visual: {"family": "transformation", "values": {"lesson": 3, "kind": "reflect_diag", "original": [[-1, -1], [2, -1], [-1, 1]], "image": [[-1, -1], [-1, 2], [1, -1]], "dx": 0, "dy": 0, "centre": [0, 0], "factor": 1, "rule": "reflection in y = x", "model": "coordinate_transform", "original_area": null}}

1. Plot and label the original vertices A(-1, -1), B(2, -1), C(-1, 1) on one fixed set of axes.

2. Mark the reflection in y = x; Swap x and y for every vertex; the line y = x stays fixed.

3. Map A (-1, -1) to A′(-1, -1); retain A and A′.

4. Map B (2, -1) to B′(-1, 2) and C (-1, 1) to C′(1, -1); join A′B′C′.

5. Check the coordinate rule on all three vertices; image A′(-1, -1), B′(-1, 2), C′(1, -1).

**Answer:** A′(-1, -1), B′(-1, 2), C′(1, -1). **Misconception:** Apply the same rule to both coordinates of every vertex; check the centre, axis and scale.
