## g9-tg-l04-w01: Triangle A(-1, -1), B(2, -1), C(-1, 1) is transformed by 90° anticlockwise rotation around (0, -1). Plot the image and give its vertex coordinates.

1. Plot and label the original vertices A(-1, -1), B(2, -1), C(-1, 1) on one fixed set of axes.

2. Mark the 90° anticlockwise rotation around (0, -1); Subtract centre (0, -1), turn each relative (x, y) into (−y, x), then add the centre.

3. Map A (-1, -1) to A′(0, -2); retain A and A′.

4. Map B (2, -1) to B′(0, 1) and C (-1, 1) to C′(-2, -2); join A′B′C′.

5. Check the coordinate rule on all three vertices; image A′(0, -2), B′(0, 1), C′(-2, -2).

**Answer:** A′(0, -2), B′(0, 1), C′(-2, -2). **Misconception:** Apply the same rule to both coordinates of every vertex; check the centre, axis and scale.
