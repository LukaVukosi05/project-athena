## g9-tg-l07-w01: A learner transforms triangle A(-1, -1), B(2, -1), C(-1, 1) by reflection in the x-axis but changes only the x-coordinate of B. Identify the first error and give the correct image.

Visual: {"family": "transformation", "values": {"lesson": 7, "kind": "reflect_x", "original": [[-1, -1], [2, -1], [-1, 1]], "image": [[-1, 1], [2, 1], [-1, -1]], "dx": 0, "dy": 0, "centre": [0, 0], "factor": 1, "rule": "reflection in the x-axis", "model": "coordinate_transform", "original_area": null}}

1. Plot and label the original vertices A(-1, -1), B(2, -1), C(-1, 1) on one fixed set of axes.

2. First error: changing only B’s x-coordinate does not apply reflection in the x-axis to every vertex. Keep x; reverse the sign of y for every vertex.

3. Map A (-1, -1) to A′(-1, 1); retain A and A′.

4. Map B (2, -1) to B′(2, 1) and C (-1, 1) to C′(-1, -1); join A′B′C′.

5. Check the coordinate rule on all three vertices; image A′(-1, 1), B′(2, 1), C′(-1, -1).

**Answer:** reflection in the x-axis; A′(-1, 1), B′(2, 1), C′(-1, -1). **Misconception:** Apply the same rule to both coordinates of every vertex; check the centre, axis and scale.
